> # Kubernetes 集群安装指南（大陆网络｜Ubuntu｜kubeadm + containerd + Flannel）
>
> > 适用：Ubuntu 20.04/22.04/24.04，x86_64/ARM64；中国大陆网络；Kubernetes **1.30.6**；示例以**单控制面**起步，可扩展到多节点。
> >
> > 你当前环境实测成功：**Control-Plane IP: 192.168.241.137**，CNI：**Flannel**，镜像加速与 DNS 已适配。
>
> ------
>
> ## 0. 目标与拓扑
>
> - **单机自用**（可在主节点上运行工作负载）：去除控制面污点后直接部署业务。
> - **多节点集群**：其他工作节点通过 `kubeadm join` 加入。
>
> ------
>
> ## 1. 所有节点通用准备（root）
>
> ```bash
> # 主机名（自选）
> hostnamectl set-hostname k8s-$(date +%H%M)
> 
> # 关闭 swap（kubelet 要求）
> swapoff -a
> sed -ri 's/.*swap.*/#&/' /etc/fstab
> 
> # 内核模块 + 内核参数
> modprobe overlay && modprobe br_netfilter
> cat > /etc/sysctl.d/99-kubernetes-cri.conf <<'EOF'
> net.bridge.bridge-nf-call-iptables=1
> net.bridge.bridge-nf-call-ip6tables=1
> net.ipv4.ip_forward=1
> EOF
> sysctl --system
> 
> # （可选）优化 DNS（大陆环境建议）
> cat >/etc/systemd/resolved.conf <<'EOF'
> [Resolve]
> DNS=223.5.5.5 119.29.29.29 114.114.114.114
> FallbackDNS=8.8.8.8 1.1.1.1
> EOF
> systemctl restart systemd-resolved
> ```
>
> ------
>
> ## 2. 安装并配置 containerd（Ubuntu）
>
> ```bash
> apt-get update
> apt-get install -y apt-transport-https ca-certificates curl gnupg lsb-release
> install -m0755 -d /etc/apt/keyrings
> curl -fsSL https://download.docker.com/linux/$(. /etc/os-release; echo "$ID")/gpg | gpg --dearmor -o /etc/apt/keyrings/docker.gpg
> 
> echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] \
> https://download.docker.com/linux/$(. /etc/os-release; echo "$ID") $(lsb_release -cs) stable" \
> > /etc/apt/sources.list.d/docker.list
> 
> apt-get update && apt-get install -y containerd.io
> 
> # 生成默认配置 + 启用 systemd cgroup
> containerd config default | tee /etc/containerd/config.toml >/dev/null
> sed -ri 's/SystemdCgroup = false/SystemdCgroup = true/' /etc/containerd/config.toml
> 
> # 统一 sandbox 镜像（避免告警）
> grep -q '^ *sandbox_image' /etc/containerd/config.toml || \
>   sed -i '/\[plugins."io.containerd.grpc.v1.cri"\]/a\  sandbox_image = "registry.aliyuncs.com/google_containers/pause:3.9"' /etc/containerd/config.toml
> 
> # 国内镜像加速
> cat >> /etc/containerd/config.toml <<'EOF'
> 
> [plugins."io.containerd.grpc.v1.cri".registry.mirrors]
>   [plugins."io.containerd.grpc.v1.cri".registry.mirrors."registry.k8s.io"]
>     endpoint = ["https://registry.aliyuncs.com/google_containers"]
>   [plugins."io.containerd.grpc.v1.cri".registry.mirrors."docker.io"]
>     endpoint = ["https://docker.m.daocloud.io","https://hub-mirror.c.163.com","https://dockerproxy.com"]
> EOF
> 
> systemctl daemon-reload && systemctl enable --now containerd
> 
> # 配置 crictl 指向 containerd（避免找 dockershim）
> cat >/etc/crictl.yaml <<'EOF'
> runtime-endpoint: unix:///run/containerd/containerd.sock
> image-endpoint: unix:///run/containerd/containerd.sock
> timeout: 10
> debug: false
> EOF
> 
> crictl info
> ```
>
> ------
>
> ## 3. 安装 kubeadm/kubelet/kubectl（阿里云源）
>
> ```bash
> curl -fsSLo /etc/apt/keyrings/kubernetes-archive-keyring.gpg \
>   https://mirrors.aliyun.com/kubernetes/apt/doc/apt-key.gpg
> 
> echo "deb [signed-by=/etc/apt/keyrings/kubernetes-archive-keyring.gpg] \
> https://mirrors.aliyun.com/kubernetes/apt/ kubernetes-xenial main" \
>   > /etc/apt/sources.list.d/kubernetes.list
> 
> apt-get update
> K8S_VERSION=1.30.6
> apt-get install -y kubelet=${K8S_VERSION}-00 kubeadm=${K8S_VERSION}-00 kubectl=${K8S_VERSION}-00
> apt-mark hold kubelet kubeadm kubectl
> systemctl enable --now kubelet
> ```
>
> > 可选：预拉取镜像
>
> ```bash
> kubeadm config images pull --image-repository registry.aliyuncs.com/google_containers
> ```

> ## 4. 初始化控制平面（在主节点）
>
> ```bash
> export POD_CIDR=10.244.0.0/16   # Flannel 推荐
> export APISERVER_ADVERTISE_ADDRESS=$(hostname -I | awk '{print $1}')
> export K8S_VERSION=1.30.6
> 
> kubeadm init \
>   --kubernetes-version v${K8S_VERSION} \
>   --apiserver-advertise-address ${APISERVER_ADVERTISE_ADDRESS} \
>   --image-repository registry.aliyuncs.com/google_containers \
>   --pod-network-cidr=${POD_CIDR}
> ```
>
> 配置 kubectl：
>
> ```bash
> # 非 root 用户：
> mkdir -p $HOME/.kube
> sudo cp -i /etc/kubernetes/admin.conf $HOME/.kube/config
> sudo chown $(id -u):$(id -g) $HOME/.kube/config
> # 若当前就是 root：
> # export KUBECONFIG=/etc/kubernetes/admin.conf
> ```

>
> ```bash

> ## 6. 单机可调度 & 连通性自测
>
> ```bash
> # 让主节点也调度工作负载（单机场景必须）
> kubectl taint nodes $(hostname) node-role.kubernetes.io/control-plane:NoSchedule-
> 
> # 部署并暴露一个 nginx
> kubectl create deploy nginx --image=docker.m.daocloud.io/library/nginx:latest --replicas=2
> kubectl rollout status deploy/nginx
> kubectl expose deploy nginx --port=80 --type=NodePort
> kubectl get svc nginx -o wide
> 
> # 例：访问 http://192.168.241.137:<NODE_PORT>
> ```
>
> > 如果镜像拉取慢，可先 `crictl pull docker.m.daocloud.io/library/nginx:latest`。

> ## 7. 多节点扩容（在每个工作节点）
>
> 1. 重复 **章节 1–3** 的准备、containerd、kubelet 安装。
> 2. 在工作节点执行控制面生成的 join 命令（示例）：
>
> ```bash
> kubeadm join 192.168.241.137:6443 --token <token> \
>   --discovery-token-ca-cert-hash sha256:<hash>
> ```
>
> 1. 回控制面查看：
>
> ```bash
> kubectl get nodes -o wide
> ```
>
> > Token 过期可在控制面重发：`kubeadm token create --print-join-command`

> ## 9. 故障速查
>
> - **`IsPrivilegedUser` 错误**：用 root 或 `sudo -i` 执行。
> - **`pause:3.8`/`3.9` 不一致告警**：在 `/etc/containerd/config.toml` 里设置
>    `sandbox_image = "registry.aliyuncs.com/google_containers/pause:3.9"`，然后 `systemctl restart containerd`。
> - **`ImagePullBackOff`**：切换镜像为 `docker.m.daocloud.io/...` 或预拉 `crictl pull`。
> - **下载 YAML 失败（DNS）**：调整 `/etc/systemd/resolved.conf` 中 DNS，或使用 jsDelivr / ghproxy 地址。
> - **CoreDNS 不 Ready**：先确保 Flannel Ready；节点出现 `cni0`/`flannel.1` 网卡后通常即恢复。

> ## 附录：一键脚本（控制节点 & 工作节点｜Ubuntu｜大陆网络）
>
> > 使用方法：把下面两段脚本分别保存为 `control-plane.sh` 与 `worker-node.sh`，并赋权执行：`chmod +x *.sh`。
> >
> > - **控制节点**：`sudo ./control-plane.sh`（默认单机可调度，自动安装 Flannel）。
> > - **工作节点**：`sudo ./worker-node.sh "<kubeadm join ...>"` ；或先 `export JOIN_COMMAND="<kubeadm join ...>"` 再执行脚本。
> >
> > 提示：你当前的 join 示例为：
> >  `kubeadm join 192.168.241.137:6443 --token h28hlb.3vzk6uc9w9c3dp19 --discovery-token-ca-cert-hash sha256:d90f78e5f093e6f382813fbfdf2c3df57ecaa3812d5e9fe3d8701e9565928448`（若已过期，可在控制面上重新生成：`kubeadm token create --print-join-command`）。

用法小抄：

2. 控制面：`sudo ./control-plane.sh`（默认单机可调度、自动装 Flannel）
3. 工作节点：`sudo ./worker-node.sh "<kubeadm join ...>"`
