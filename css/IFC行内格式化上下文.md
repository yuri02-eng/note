### **一、IFC 是什么？**
**行内格式化上下文（IFC）** 是CSS渲染页面时的一种布局环境，用于控制**行内级元素**（如文本、`<span>`、`<img>`等）在水平方向上的排列与对齐。

---

### **二、触发条件**
IFC 在以下情况自动创建：
1. 元素包含**行内级内容**（文本、`inline`、`inline-block`、`inline-table`等）。
2. **块级容器**（如`<div>`、`<p>`）内部存在行内级元素时。

---

### **三、核心布局规则**
#### 1. **水平排列**
- 元素从左到右水平排列，直到容器宽度不足时换行。
- 换行后形成新的**行框（Line Box）**。

#### 2. **行框（Line Box）**
- 每行文本或行内元素构成一个矩形区域（行框）。
- 行框高度由该行内最高元素的**行高（line-height）** 决定。
- 行框宽度等于父容器宽度（减去浮动元素占用的空间）。

#### 3. **垂直对齐**
- 通过 `vertical-align` 属性控制行内元素在行框内的垂直对齐方式（默认基线对齐 `baseline`）。
- 常见值：`top`、`middle`、`bottom`、`text-top`、`text-bottom`。

#### 4. **空白处理**
- 空格、换行符会被合并为一个空格。
- 可通过 `white-space` 属性控制（如 `nowrap` 禁止换行）。

---

### **四、IFC 的特性**
1. **高度由内容撑开**  
   容器高度由行框高度累加决定（不显式设置 `height`）。
2. **不支持垂直外边距合并**  
   行内元素的 `margin-top` 和 `margin-bottom` 无效。
3. **水平方向有效**  
   `padding`、`border`、`margin` 在水平方向生效，不影响行高计算（除非 `inline-block`）。
4. **文本自动换行**  
   容器宽度不足时自动换行（除非 `white-space: nowrap`）。

---

### **五、常见应用场景**
#### 1. **文本居中**
```css
.container {
  text-align: center; /* 水平居中（在IFC中生效） */
  line-height: 200px; /* 垂直居中（需配合容器高度） */
}
```

#### 2. **行内元素对齐**
```css
.icon {
  vertical-align: middle; /* 图标与文本中线对齐 */
}
```

#### 3. **多行文本省略**
```css
.text {
  display: -webkit-inline-box; /* 模拟IFC换行 */
  -webkit-box-orient: vertical;
  -webkit-line-clamp: 2; /* 限制2行 */
  overflow: hidden;
}
```

#### 4. **解决间隙问题**
行内元素间的空格符可能导致间隙：
```html
<!-- 方案1：移除标签间空格 -->
<span>文本</span><span>内容</span>

<!-- 方案2：父容器设置 font-size:0 -->
<div style="font-size:0">
  <span style="font-size:16px">文本</span>
  <span style="font-size:16px">内容</span>
</div>
```

---

### **六、IFC 与 BFC 的区别**
| **特性**         | **IFC**                     | **BFC**                     |
|------------------|----------------------------|-----------------------------|
| **排列方向**     | 水平                       | 垂直                        |
| **元素类型**     | 行内级元素                 | 块级元素                    |
| **高度计算**     | 由行框高度累加             | 由包含元素决定或显式设置    |
| **外边距合并**   | 垂直方向无效               | 阻止外边距合并              |
| **浮动影响**     | 行框避开浮动元素           | 包含内部浮动                |

---

### **总结**
- **IFC 控制行内元素的水平排列与对齐**，是文本布局的基础机制。
- 理解行框、`vertical-align` 和空白处理是掌握IFC的关键。
- 结合 `inline-block` 可模拟块级布局效果，同时保留行内特性（如水平居中文本）。

掌握IFC有助于解决日常开发中的文本对齐、间隙问题及构建灵活布局！
