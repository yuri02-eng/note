### **C++ 模板（Template）详细笔记**

C++ 模板是实现泛型编程的一个重要特性，允许我们编写通用的函数或类，处理不同的数据类型。通过模板，我们可以在编译时根据实际的数据类型生成相应的代码，从而避免重复代码的编写。

下面是关于 C++ 模板的详细笔记，涵盖了函数模板、类模板、模板特化、非类型模板参数等核心概念。

---

### **1. 模板的基本概念**

**模板**是C++中允许在编译时生成代码的机制，主要分为函数模板和类模板。

* **函数模板**：让函数在处理不同类型时保持通用。
* **类模板**：让类在处理不同类型时保持通用。

模板的核心思想是：**定义一个模板，通过传入不同的类型或参数来生成不同的函数或类实例**。

#### **模板的定义格式**

* **函数模板的定义格式**：

  ```cpp
  template <typename T>  // T是类型参数，可以在函数中使用
  T add(T a, T b) {
      return a + b;
  }
  ```

* **类模板的定义格式**：

  ```cpp
  template <typename T>  // T是类型参数
  class MyClass {
  private:
      T data;  // data的类型是T
  public:
      void setData(T val) { data = val; }
      T getData() { return data; }
  };
  ```

* **模板参数**：

  * **类型模板参数**：`typename T` 或 `class T`。`T` 代表一个类型参数，允许在函数或类中使用该类型。
  * **非类型模板参数**：用于传递常量值，如整数、指针等。

---

### **2. 函数模板（Function Templates）**

**函数模板**允许我们编写一个函数的泛型实现，以便处理多种类型。编译器会根据实际传入的类型生成特定类型的函数。

#### **函数模板的实例**

```cpp
template <typename T>  // T是类型参数
T add(T a, T b) {
    return a + b;
}

int main() {
    std::cout << add(2, 3) << std::endl;  // 传入int类型
    std::cout << add(2.5, 3.5) << std::endl;  // 传入double类型
    return 0;
}
```

* **模板实例化**：编译器会根据 `add(2, 3)` 调用生成 `add<int>`，根据 `add(2.5, 3.5)` 生成 `add<double>`。

#### **模板参数的推导**

编译器根据函数调用时传入的参数类型自动推导出模板参数类型。

```cpp
template <typename T>
void print(T value) {
    std::cout << value << std::endl;
}

int main() {
    print(5);  // 推导出T为int
    print("Hello, world!");  // 推导出T为const char*
}
```

---

### **3. 类模板（Class Templates）**

**类模板**允许我们为不同的数据类型创建通用类。类模板与函数模板的使用方法类似，不同之处在于它们用于类的定义。

#### **类模板实例**

```cpp
template <typename T>
class Box {
private:
    T value;  // value的类型由模板参数T决定
public:
    void setValue(T val) { value = val; }
    T getValue() { return value; }
};

int main() {
    Box<int> intBox;  // 实例化为int类型
    intBox.setValue(5);
    std::cout << intBox.getValue() << std::endl;

    Box<double> doubleBox;  // 实例化为double类型
    doubleBox.setValue(3.14);
    std::cout << doubleBox.getValue() << std::endl;

    return 0;
}
```

#### **类模板的实例化**

与函数模板一样，类模板在编译时实例化。在上述代码中，`Box<int>` 和 `Box<double>` 是 `Box` 模板的两个实例。

---

### **4. 模板特化（Template Specialization）**

**模板特化**允许我们为特定类型或特定条件提供专门的实现。模板特化有两种类型：**完全特化** 和 **部分特化**。

#### **完全特化（Full Specialization）**

完全特化是指为特定类型提供完整的定制实现。

```cpp
template <typename T>
class Box {
public:
    T value;
    void print() { std::cout << value << std::endl; }
};

// 针对 int 类型的特化
template <>
class Box<int> {
public:
    int value;
    void print() { std::cout << "Specialized Box for int: " << value << std::endl; }
};
```

在这个例子中，`Box<int>` 会使用特化版本的 `print()` 方法，而其他类型则使用通用版本。

#### **部分特化（Partial Specialization）**

部分特化是指只为模板中的某些参数提供定制化的实现，而其他部分保持通用。

```cpp
template <typename T, typename U>
class Pair {
public:
    T first;
    U second;
};

// 针对相同类型的部分特化
template <typename T>
class Pair<T, T> {
public:
    T first;
    T second;
    void print() { std::cout << first << " and " << second << std::endl; }
};
```

这里，`Pair<T, T>` 是 `Pair` 的部分特化，当两个类型相同时，提供定制的 `print()` 方法。

---

### **5. 非类型模板参数（Non-Type Template Parameters）**

**非类型模板参数**允许模板接受常量值作为参数，例如整数、指针、引用等，而不是仅限于类型参数。

#### **使用非类型模板参数**

```cpp
template <typename T, int size>  // size 是一个非类型模板参数
class StaticArray {
private:
    T arr[size];  // 使用非类型参数控制数组大小
public:
    T& operator[](int index) {
        return arr[index];
    }
};
```

在上面的例子中，`StaticArray<int, 5>` 声明了一个长度为 5 的整数数组。

---

### **6. 模板的实例化**

模板的实例化是指根据实际的类型或常量值生成具体的函数或类。当我们调用模板时，编译器会根据传入的类型或常量来实例化模板。

#### **隐式实例化**

编译器根据参数类型自动推导出模板参数并进行实例化。

```cpp
template <typename T>
void print(T val) { std::cout << val << std::endl; }

print(5);  // 编译器推导出 T 为 int
print(3.14);  // 编译器推导出 T 为 double
```

#### **显式实例化**

我们可以通过显式指定类型来实例化模板，通常用于减少模板实例化的开销。

```cpp
template class Box<int>;  // 显式实例化 Box<int>
template class Box<double>;  // 显式实例化 Box<double>
```

---

### **7. 模板的优势和注意事项**

#### **优势**

* **代码复用**：模板使得我们可以编写通用代码，避免为每个数据类型编写重复的函数或类。
* **类型安全**：模板会在编译时根据类型检查代码，避免了运行时的类型错误。
* **灵活性**：可以根据实际的类型或常量动态生成代码。

#### **注意事项**

* **模板实例化增加编译时间**：模板的实例化会增加编译时间，特别是在模板被多次使用时。
* **错误信息不直观**：模板相关的错误信息往往难以理解，因为模板是在编译时进行实例化的，错误可能涉及多个模板参数。
* **调试困难**：由于模板代码在编译时生成，调试模板相关的错误可能会更加复杂。

---

### **总结**

C++ 模板是一个非常强大的工具，允许开发者编写通用的函数和类来处理不同的数据类型。通过模板特化、部分特化和非类型模板参数，模板提供了极大的灵活性，可以使程序更加简洁、可维护、类型安全。同时，模板也能提高代码的复用性，减少冗余代码的编写，是现代 C++ 编程的重要组成部分。
