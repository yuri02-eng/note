### CSS Position 属性全面总结

`position` 属性定义了元素在文档中的定位方式。它是 CSS 布局的核心基础之一。

#### 一、核心概念：定位上下文（Containing Block）
元素定位的参考坐标系原点。**默认的定位上下文是浏览器视口（viewport）**，但当元素被设置了某些 `position` 值后，它会为其绝对定位的后代元素创建一个新的定位上下文。

---

#### 二、五个定位值详解

| 值 | 描述 | 是否脱离文档流 | 定位上下文 |
| :--- | :--- | :--- | :--- |
| `static` | **默认值**。元素按正常文档流排列。 | 否 | 正常文档流 |
| `relative` | **相对定位**。相对于其**自身原本的位置**进行偏移。 | **否**（占原空间） | 自身原本的位置 |
| `absolute` | **绝对定位**。相对于**最近的非 `static` 定位祖先元素**定位。 | **是**（不占空间） | 最近的非 `static` 祖先 |
| `fixed` | **固定定位**。相对于**浏览器视口（viewport）** 定位。 | **是**（不占空间） | 视口（viewport） |
| `sticky` | **粘性定位**。在特定阈值前为相对定位，之后变为固定定位。 | **否**（占原空间，直到固定） | 视口（或滚动容器） |

---

#### 三、各定位模式深度解析

##### 1. `static` (默认定位)
- 元素遵循正常的文档流。
- `top`, `right`, `bottom`, `left`, `z-index` 属性**无效**。
- **使用场景**：用于重置元素的定位。

##### 2. `relative` (相对定位)
- **特点**：
    - 偏移后，**原本在文档流中所占的空间仍然保留**，不会影响其他元素的位置。
    - 常与 `top`, `bottom`, `left`, `right` 配合使用。
- **代码示例**：
    ```css
    .box {
      position: relative;
      top: 20px; /* 向下移动20px */
      left: 30px; /* 向右移动30px */
    }
    ```
- **使用场景**：
    - 微调元素位置。
    - **作为 `absolute` 定位子元素的“容器”**（非常常用）。

##### 3. `absolute` (绝对定位)
- **特点**：
    - 元素**脱离正常文档流**，不再占用空间。
    - 其位置由 `top`, `right`, `bottom`, `left` 和**最近的已定位祖先元素**（即 `position` 不为 `static` 的元素）共同决定。
    - 如果没有任何祖先被定位，则相对于 `<html>` 文档（即视口）进行定位。
- **代码示例**：
    ```html
    <!-- HTML -->
    <div class="container">
      <div class="absolute-box">我绝对定位了！</div>
    </div>
    ```
    ```css
    /* CSS */
    .container {
      position: relative; /* 为子元素创建定位上下文 */
      width: 400px;
      height: 200px;
      border: 1px solid #ccc;
    }
    .absolute-box {
      position: absolute;
      bottom: 10px;
      right: 10px;
    }
    ```
- **使用场景**：
    - 创建不干扰其他元素的弹出层、模态框、工具提示。
    - 图标角标。
    - 控制元素在特定容器内的精确位置。

##### 4. `fixed` (固定定位)
- **特点**：
    - 元素**脱离正常文档流**。
    - 定位上下文始终是**浏览器视口**。
    - 页面滚动时，元素位置**固定不变**。
    - 常与 `top`, `right`, `bottom`, `left` 配合使用（通常设为 `0`）。
- **代码示例**：
    ```css
    .fixed-header {
      position: fixed;
      top: 0;
      left: 0;
      width: 100%;
      background: #333;
      color: white;
    }
    ```
- **使用场景**：
    - 固定顶部的导航栏、底部的播放控件。
    - “回到顶部”按钮。
    - 固定侧边栏。

##### 5. `sticky` (粘性定位)
- **特点**：
    - 可以看作是 `relative` 和 `fixed` 的混合。
    - 元素在跨越特定阈值前为相对定位，之后为固定定位。
    - 必须指定 `top`, `right`, `bottom`, `left` 中的一个阈值才会生效。
    - **在其父容器内生效**。当父容器离开视口时，粘性元素也会随之滚动离开。
- **代码示例**：
    ```css
    .sticky-header {
      position: -webkit-sticky; /* 兼容 Safari */
      position: sticky;
      top: 0; /* 当元素滚动到距离视口顶部0px时，变为固定定位 */
    }
    ```
- **使用场景**：
    - 表格的表头。
    - 长页面中的分类标题。

---

#### 四、配合使用的属性

- `top`, `right`, `bottom`, `left`：定义元素相对于其**定位上下文**的偏移量。
- `z-index`：控制定位元素（非 `static`）的堆叠顺序。**数值越大，元素越在上层**。仅对定位元素有效。

---

#### 五、实用技巧与注意事项

1.  **“父相子绝”**：
    这是一个非常经典且实用的口诀。如果你想精确控制一个元素在某个容器内的位置，应该：
    - 给**父容器**设置 `position: relative;`（创建定位上下文）。
    - 给**子元素**设置 `position: absolute;`，然后使用 `top`, `left` 等定位。

2.  **`absolute` 与 `fixed` 会导致元素脱离文档流**，可能会遮挡其他内容，需要合理规划布局和 `z-index`。

3.  **`sticky` 的兼容性**：虽然现代浏览器都已支持，但一些旧版本（如 IE）完全不支持。`position: -webkit-sticky;` 是 Safari 所需的前缀。

4.  **`fixed` 在移动端的怪异表现**：在某些移动端浏览器中，`fixed` 的表现可能不如预期（例如，会相对于某个网页容器而非视口定位）。需要仔细测试。

5.  **`z-index` 只在同一 stacking context (层叠上下文) 内比较**。如果父元素的 `z-index` 很低，那么子元素的 `z-index` 再高也无法超越其他 stacking context 中更高 `z-index` 的元素。

#### 总结表格（快速查阅）

| 定位方式 | 参考系 | 是否脱流 | 常用场景 |
| :--- | :--- | :--- | :--- |
| `static` | 正常流 | 否 | 默认布局，重置定位 |
| `relative` | 自身原位置 | 否（占位） | 微调，作为绝对定位的容器 |
| `absolute` | 最近非static祖先 | 是 | 弹出层，图标角标，精准定位 |
| `fixed` | 浏览器视口 | 是 | 固定导航栏，悬浮按钮 |
| `sticky` | 视口（到达阈值后） | 否（占位） | 滚动吸顶 |
