### **CSS 优先级计算 - 真实情况详解**

## **一、 核心概念：优先级是什么？**

*   **目的：** 当多条 CSS 规则同时声明了同一个元素的同一个属性时，浏览器需要决定应用哪条规则的值。
*   **机制：** 浏览器为每个**选择器**计算一个**优先级权重值**。权重值高的规则覆盖权重值低的规则。
*   **关键点：** 优先级是**基于选择器本身**计算的，与规则的位置（行内、内部、外部）或属性值无关（除非使用 `!important`）。

## **二、 优先级权重的构成（核心模型）**

浏览器和规范（如 W3C Selectors Level 3/4）将优先级权重概念化为一个由 **4 个分量** 组成的值，通常表示为 `(a, b, c, d)` 或 `0,0,0,0`：

1.  **`a` - 内联样式计数：**
    *   对应直接在 HTML 元素的 `style` 属性中声明的样式。
    *   **规则：** 如果存在内联样式，则 `a = 1`；否则 `a = 0`。
    *   **权重：** `a=1` 的规则**必然**覆盖任何 `a=0` 的规则（不考虑 `!important`）。这是最高级别的分量。

2.  **`b` - ID 选择器计数：**
    *   计算选择器中 **ID 选择器** (`#someId`) 的数量。
    *   **规则：** 一个 ID 选择器使 `b += 1`。
    *   **权重：** `b` 分量比 `c` 和 `d` 分量具有更高的权重。

3.  **`c` - 类、属性、伪类选择器计数：**
    *   计算选择器中以下选择器的数量：
        *   **类选择器** (`.someClass`)
        *   **属性选择器** (`[type="text"]`, `[href^="https"]`)
        *   **伪类** (`:hover`, `:focus`, `:nth-child(n)`, `:not(...)`)
    *   **规则：** 上述每类选择器出现一次，`c += 1`。
    *   **特别注意 `:not()`：**
        *   `:not()` 伪类**本身**不增加权重。
        *   但**传入 `:not()` 括号内的选择器会正常计算权重**。例如 `:not(#id)` 中的 `#id` 会使 `b += 1`；`:not(.class)` 中的 `.class` 会使 `c += 1`。

4.  **`d` - 元素、伪元素选择器计数：**
    *   计算选择器中以下选择器的数量：
        *   **元素（标签）选择器** (`div`, `p`, `span`)
        *   **伪元素** (`::before`, `::after`)
    *   **规则：** 上述每类选择器出现一次，`d += 1`。

**重要说明：**

* **通配符 (`*`)、组合符 (`+`, `>`, `~`, ` `)、通用选择符 (`:where()`)：** 这些选择器**本身**对优先级权重 (`a, b, c, d`) **没有任何贡献** (`0,0,0,0`)。

* **`:is()` 和 `:has()` 伪类：** 它们的优先级等于其**参数列表中最高的优先级**。例如 `:is(#id, .class)` 的优先级等于 `#id` (`0,1,0,0`)。

  ### 计算规则

  1. **内联样式** (`style="..."`): `a = 1`
  2. **ID 选择器** (`#id`): 每个使 `b += 1`
  3. **类/属性/伪类选择器**:
     - 类选择器 (`.class`)
     - 属性选择器 (`[type="text"]`)
     - 伪类 (`:hover`, `:focus`, `:nth-child()`)
     - 每个使 `c += 1`
  4. **元素/伪元素选择器**:
     - 元素选择器 (`div`, `p`)
     - 伪元素 (`::before`, `::after`)
     - 每个使 `d += 1`

  ### 特殊选择器处理

  - **通配符** (`*`), **组合符** (`+`, `>`, `~`, ` `): 不增加任何权重 (`0,0,0,0`)
  - **`:not()` 伪类**: 本身不增加权重，但内部选择器正常计算
  - **`:is()` 和 `:has()` 伪类**: 优先级等于其参数列表中最高优先级的选择器
  - **通用选择符** (`:where()`): 总是 `0,0,0,0`

## **三、 权重比较规则（真实逻辑）**

浏览器在比较两个选择器的优先级时，**并非**简单地将 `(a, b, c, d)` 当作一个四元组或拼接成一个十进制数来比较。其内部逻辑是：

1.  **分量优先级：** `a` > `b` > `c` > `d`。
2.  **逐位比较：**
    *   首先比较 `a` 分量。`a` 值大的选择器胜出。
    *   如果 `a` 相等，则比较 `b` 分量。`b` 值大的选择器胜出。
    *   如果 `a` 和 `b` 都相等，则比较 `c` 分量。`c` 值大的选择器胜出。
    *   如果 `a`, `b`, `c` 都相等，则比较 `d` 分量。`d` 值大的选择器胜出。
3.  **全部相等：** 如果 `(a, b, c, d)` 四个分量**完全相等**，则**后声明的规则**（在 CSS 文件或 `<style>` 块中位置靠后的）覆盖先声明的规则（源码顺序）。

**为什么不是简单的十进制数？**
*   考虑选择器 `#id` (`a=0, b=1, c=0, d=0`) 和选择器 `.class(`a=0, b=0, c=10, d=0`)。
*   如果拼接成 `0100` vs `0010`，数值上 `100` > `10`，`#id` 胜出，这是正确的（`b` 分量更高）。
*   但如果浏览器真的用十进制数 `100` 和 `10` 比较，逻辑也成立。
*   **问题在于进制：** 实际上，浏览器内部可能会使用一个足够大的进制（如 256 或 65536）来表示这个权重，确保 `b` 分量的一个单位永远比 `c` 分量的最大值（比如 255 个类）还要大。但这只是实现细节，**比较规则严格按照 `a > b > c > d` 的分量顺序进行**。

### 比较示例

| 选择器 A | 选择器 B | 结果 |
|---------|---------|------|
| `(0,1,0,0)` | `(0,0,12,0)` | A 胜出 (`b=1` > `b=0`) |
| `(0,0,2,0)` | `(0,0,1,5)` | A 胜出 (`c=2` > `c=1`) |
| `(0,0,1,3)` | `(0,0,1,2)` | A 胜出 (`c`相等，`d=3` > `d=2`) |
| `(0,0,1,2)` | `(0,0,1,2)` | 后定义的胜出 |

## 四、复合选择器计算详解

### 1. 基础复合选择器
- `li.active` → 1元素 + 1类 → `(0,0,1,1)`

### 2. 后代/子选择器
- `ul li.active` → 2元素 + 1类 → `(0,0,1,2)`
- `ul > li.active` → 同上，组合符不计数 → `(0,0,1,2)`

### 3. 多类/属性/伪类组合
- `input[type="text"].username:focus` → 1元素 + 1属性 + 1类 + 1伪类 → `(0,0,3,1)`

### 4. 包含 `:not()` 的选择器
- `div:not(.ignore)` → `:not`不计，但`.ignore`计 → 1元素 + 1类 → `(0,0,1,1)`

## 五、优先级权重等级

从高到低：

1. **`!important`**: 最高优先级（应避免滥用）
2. **内联样式**: `(1,0,0,0)`
3. **ID 选择器**: `(0,1,0,0)`
4. **类/属性/伪类选择器**: `(0,0,1,0)` 到 `(0,0,n,0)`
5. **元素/伪元素选择器**: `(0,0,0,1)` 到 `(0,0,0,n)`
6. **通配符、组合符**: `(0,0,0,0)`

## 七、特殊规则与注意事项

1. **`!important`**:
   - 覆盖所有优先级规则
   - 多个 `!important` 冲突时，它们之间再按正常优先级比较
   - 应尽量避免使用

2. **继承样式**:
   - 从父元素继承的样式优先级为 `(0,0,0,0)`
   - 任何直接指定的样式都会覆盖继承样式

3. **用户代理样式**:
   - 浏览器默认样式，优先级很低
   - 通常为元素选择器级别 `(0,0,0,1)` 或类似

4. **源码顺序**:
   - 当优先级完全相同时，后定义的规则生效

## 八、最佳实践与建议

1. **多用类，少用ID**: 类选择器更易于覆盖和维护
2. **保持简洁**: 避免过于复杂的选择器，防止优先级过高
3. **利用源码顺序**: 合理组织CSS代码顺序
4. **避免`!important`**: 除非绝对必要，否则不要使用
5. **使用工具**: 浏览器开发者工具可查看计算后的优先级
6. **理解新伪类**: 掌握 `:not()`, `:is()`, `:has()` 的优先级计算方式

## 九、记忆口诀

> 行内ID类元素，四位权重逐级比
> important是核武，滥用维护成难题
> 继承样式权重零，后写规则能覆盖
> 多用类来少用ID，代码简洁易维护
