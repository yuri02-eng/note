# 🟦 **阶段 1（第 1–3 周）：C++ 基础 + 网络编程能力建立**

### **Week 1：现代 C++ 入门**

目标：掌握能写网络程序的 C++11 基础

**学习内容**

* RAII
* 构造函数 / 析构函数
* 智能指针（unique_ptr / shared_ptr）
* STL（vector、unordered_map、string）
* auto、range-for、lambda表达式

**练习**

* 用 C++ 写一个简单的命令行工具：
  “扫描一个文件夹，输出所有文件名”

---

### **Week 2：C++ 多文件工程化能力 + Makefile**

目标：可以写一个 3–5 文件的工程

**学习内容：**

* 多文件工程结构
* 头文件与文件分离
* 最小可用 Makefile
* 简单调试（gdb）

**练习：**

* 写一个 C++ mini HTTP 服务器（返回固定字符串）

---

### **Week 3：C/C++ 网络编程基础**

目标：能用 C++ 写 Socket 编程

**学习内容：**

* TCP 连接流程（accept、connect）
* UDP 套接字
* 非阻塞 IO 基础（理解即可）

**练习：**

* C++ 写一个 TCP Echo Server
* 分别用 netcat 测试它

---

# 🟩 **阶段 2（第 4–6 周）：Linux 内核网络 + 虚拟网络打牢**

### **Week 4：Linux 网络栈（收包路径）**

目标：理解 NIC → DMA → 中断 → NAPI → skb → 协议栈

**学习内容：**

* NAPI / softirq
* skb 结构
* Linux 收包路径
* 路由流程（local vs forward）

**实验：**

* 用 tcpdump 抓包：比较 INPUT / FORWARD
* 画一张“收包路径图”

---

### **Week 5：Netfilter / iptables / nftables**

目标：知道 Netfilter 在协议栈的确切位置

**学习内容：**

* PREROUTING / INPUT / FORWARD / OUTPUT / POSTROUTING
* NAT、conntrack 基础（了解即可）

**实验：**

* iptables 配置 ACCEPT / DROP
* 对照抓包验证链的触发

---

### **Week 6：虚拟网络（namespace / veth / bridge）**

目标：掌握“自己搭网络拓扑”的能力

**学习内容：**

* network namespace
* veth pair
* Linux bridge
* TUN/TAP（了解）

**实验：**

* 用 namespace 构建 “Host A → Bridge → Host B”
* ping 实验，并抓包

---

# 🟥 **阶段 3（第 7–9 周）：eBPF / XDP 完整掌握（核心阶段）**

### **Week 7：eBPF 基础 + XDP 入门**

目标：能写最基础的 XDP 程序

**学习内容：**

* XDP 挂载点
* data/data_end 越界检查
* map（HASH / ARRAY）
* verifier 原理（基础理解）

**练习：**

* 写一个 XDP 程序丢弃特定源IP
* 写一个统计流量的 XDP 程序

---

### **Week 8：eBPF 网络协议解析**

目标：能解析 L2/L3/L4 头

**学习内容：**

* 以太网头
* IPv4 头
* TCP/UDP 头
* bpf_htons/bpf_ntohl 的作用
* 基于端口/IP 的过滤

**练习：**

* XDP 过滤 HTTP（port 80）
* XDP 过滤某个 TCP 源端口

---

### **Week 9：用户态与内核态通信（map 操作）**

目标：能实现动态更新 XDP 规则

**学习内容：**

* Python/bcc 更新 BPF maps
* C++ libbpf 简单示例
* 数据平面规则更新

**练习：**

* 写一个 CLI：

  * “add rule”
  * “delete rule”
  * 然后同步到 XDP map

---

# 🟪 **阶段 4（第 10–12 周）：SDN + 综合项目产出（简历大招）**

### **Week 10：SDN / OpenFlow 强化学习**

目标：能重新实现一个 L3 防火墙

**学习内容：**

* OpenFlow pipeline（表0→1→2）
* 匹配字段
* Ryu 控制器编程

**练习：**

* 用 Ryu 重写一个 L3/L4 防火墙
* 用 Mininet 测试

---

### **Week 11：综合项目实现（OpenFlow + eBPF 双平面防火墙）**

这个是关键！

**控制面（Python）：**

* 策略管理 API（REST）
* 存储规则（JSON/SQLite）

**OpenFlow 数据面：**

* 从策略生成 flow_entry
* 下发流表
* mininet 环境验证

**eBPF 数据面：**

* XDP 程序解析 L3/L4
* 根据 map 规则 DROP 或 PASS

**策略同步模块：**

* Python/C++ 程序：

  * 获取策略
  * 转换成 OF 规则
  * 同步写入 eBPF map
