# Kubernetes 常用命令速查（实战版）

> 面向日常运维与排障，命令均可直接复制使用；默认命名空间 `default`，必要时加 `-n <ns>`。
>
> [命令行工具 (kubectl) | Kubernetes](https://kubernetes.io/zh-cn/docs/reference/kubectl/) 

------

## 0. 快速约定

- 加 `-o wide` 看更多信息；`-w` 实时 watch；`--show-labels` 展示标签。
- JSONPath 常用：`-o jsonpath='{.items[*].metadata.name}'`。
- 选 Pod：`-l key=value`；选命名空间：`-n <ns>`。

------

## 0.5 命令 → 作用一览（最常用）

- `kubectl cluster-info`：显示 API Server / Core 组件的访问地址，快速确认集群可用。
- `kubectl version --short`：查看客户端/服务端版本，排查版本不匹配。
- `kubectl get nodes -o wide`：列出所有节点及角色、K8s 版本、内核、IP 等。
- `kubectl describe node <node>`：查看节点详细状态（容量/分配/污点/事件）。
- `kubectl taint nodes <node> k=v:NoSchedule`：给节点加污点，阻止未容忍的 Pod 调度上去。
- `kubectl drain <node>`：排空节点（驱逐可驱逐的 Pod），用于维护/下线。
- `kubectl cordon|uncordon <node>`：禁止/允许新 Pod 调度到该节点。
- `kubectl get all -n <ns>`：查看命名空间内常见资源（Pod/Service/Deploy 等）。
- `kubectl get pods -o wide --show-labels`：查看 Pod 运行在哪个节点、Pod IP、标签等。
- `kubectl describe pod <pod>`：查看 Pod 事件、容器状态、探针结果（排障关键）。
- `kubectl logs <pod> [-c <container>] -f`：查看容器日志；`-f` 实时跟随。
- `kubectl exec -it <pod> -- sh`：进入容器内执行命令，现场诊断。
- `kubectl run -it --rm dns --image=busybox:stable -- sh`：启动一次性调试 Pod（带 nslookup/wget）。
- `kubectl port-forward svc/<svc> 8080:80`：把本机端口映射到 Service/Pod，开发调试免改防火墙。
- `kubectl cp <ns>/<pod>:path ./`：在本机与容器之间复制文件。
- `kubectl create deploy <name> --image=<img> --replicas=N`：快速创建 Deployment。
- `kubectl scale deploy/<name> --replicas=N`：调整副本数（水平扩缩容）。
- `kubectl rollout status/history/undo deploy/<name>`：查看发布进度/历史并回滚。
- `kubectl set image deploy/<name> 容器名=镜像:tag`：滚动更新镜像。
- `kubectl expose deploy/<name> --type=NodePort`：从工作负载一键暴露 Service。
- `kubectl get svc/ep/endpointslice`：查看入口与后端池的对应关系。
- `kubectl patch svc <name> -p '{...nodePort...}'`：固定 NodePort 端口。
- `kubectl get events --sort-by=.lastTimestamp`：按时间查看近期事件（拉镜像失败/调度失败等）。
- `kubectl edit <kind>/<name>`：在线编辑资源（快速小改）；`kubectl diff -f` 预览变更。
- `kubectl apply|delete -f file.yaml`：声明式创建/删除资源。
- `iptables-save | egrep 'KUBE-'`：在节点上查看 kube-proxy 的 iptables 规则（ClusterIP/NodePort 转发表）。
- `ipvsadm -Ln`：在节点上查看 IPVS 虚拟服务与后端（若 kube-proxy 使用 IPVS）。
- `ip -br a` / `ip route`：查看 CNI 接口与路由，确认 10.244.0.0/16 的去向。

## 1) 集群与节点

```bash
# 集群信息 / 版本
kubectl cluster-info
kubectl version --short

# 节点列表 / 详细
kubectl get nodes -o wide
kubectl describe node $(hostname)

# 污点与容忍
kubectl taint nodes <node> key=value:NoSchedule
kubectl taint nodes <node> key:NoSchedule-   # 移除

# 排空/禁止调度/恢复
kubectl drain <node> --ignore-daemonsets --delete-emptydir-data
kubectl cordon <node>
kubectl uncordon <node>
```

## 2) 命名空间 / 资源浏览

```bash
kubectl get ns
kubectl get all -n <ns>

# 常用资源
kubectl get pods [-n <ns>] -o wide --show-labels
kubectl get deploy,ds,sts,svc,ep,ing -o wide
kubectl get cm,secret,pvc,pv -A
```

## 3) Pod 与容器

```bash
# 查看/进入/日志
kubectl get pod <pod> -o wide
kubectl describe pod <pod>
kubectl logs <pod> [-c <container>] --tail=200 -f
kubectl exec -it <pod> [-c <container>] -- sh

# 创建一次性调试 Pod（BusyBox 带 wget/nslookup）
kubectl run -it --rm dns --image=docker.m.daocloud.io/library/busybox:stable --restart=Never -- sh

# 端口转发（本机→Service/Pod）
kubectl port-forward svc/<svc> 8080:80
kubectl port-forward pod/<pod> 8081:8080

# 文件复制
kubectl cp <ns>/<pod>:/path/in/pod ./local-file
kubectl cp ./local-file <ns>/<pod>:/path/in/pod
```

## 4) Deployment / 副本 / 发布

```bash
# 创建/扩缩容/状态
kubectl create deploy web --image=docker.m.daocloud.io/library/nginx:latest --replicas=2
kubectl scale deploy/web --replicas=4
kubectl rollout status deploy/web

# 镜像更新（滚动发布）
kubectl set image deploy/web nginx=docker.m.daocloud.io/library/nginx:1.27

# 回滚
kubectl rollout history deploy/web
kubectl rollout undo deploy/web [--to-revision=2]
```

## 5) Service / Endpoints / Ingress

```bash
# 创建 Service（ClusterIP / NodePort）
kubectl expose deploy/web --port=80 --target-port=80 --type=ClusterIP
kubectl expose deploy/web --port=80 --target-port=80 --type=NodePort

# 查看入口与后端池
kubectl get svc web -o wide
kubectl get endpoints web -o wide
kubectl get endpointslice -l kubernetes.io/service-name=web -o wide

# 固定 NodePort（例：30080）
kubectl patch svc web -p '{"spec":{"type":"NodePort","ports":[{"port":80,"targetPort":80,"nodePort":30080}]}}'

# Headless Service（clusterIP: None）示例
cat <<'YAML' | kubectl apply -f -
apiVersion: v1
kind: Service
metadata: { name: web-headless }
spec:
  clusterIP: None
  selector: { app: web }
  ports: [{ name: http, port: 80, targetPort: 80 }]
YAML

# Ingress（需安装 ingress-nginx）
kubectl get ing -A -o wide
```

## 6) DNS / 解析测试（CoreDNS）

```bash
# kube-dns 的 ClusterIP
kubectl -n kube-system get svc kube-dns -o wide

# Pod 内查看 resolv.conf + 解析 + HTTP 访问
kubectl run -it --rm dns --image=docker.m.daocloud.io/library/busybox:stable --restart=Never -- \
  sh -c 'echo "=== resolv.conf ==="; cat /etc/resolv.conf; echo; \
         echo "=== nslookup web.default.svc.cluster.local ==="; nslookup web.default.svc.cluster.local || true; echo; \
         echo "=== HTTP to web ==="; wget -S -O- http://web 2>&1 | head -n 20 || true'
```

## 7) Label / Selector / JSONPath

```bash
# 查看标签
kubectl get pods -l app=web --show-labels

# 打/改/删标签
kubectl label pod <pod> tier=fe --overwrite=true
kubectl label pod <pod> tier-   # 删除标签

# JSONPath 常用
kubectl get pods -o jsonpath='{.items[*].metadata.name}'
kubectl get svc web -o jsonpath='{.spec.selector}'
kubectl get endpoints web -o jsonpath='{range .subsets[*].addresses[*]}{.ip}{"\n"}{end}'
```

## 9) 网络与数据面（节点上执行）

```bash
# CNI 接口与路由
ip -br a | egrep 'cni0|flannel'
ip route | egrep '10\.244|cni0|flannel'

# kube-proxy 数据面（择一）
# iptables 模式：
sudo iptables-save | egrep 'KUBE-SVC|KUBE-SEP|10\.|web'
# IPVS 模式：
sudo ipvsadm -Ln | egrep -A3 'KUBE|:80'
```

## 12) 常见一键排障脚本

```bash
# 一次性验证：DNS → Service → 后端 Pod
kubectl delete pod dns --ignore-not-found
kubectl run -it --rm dns --image=docker.m.daocloud.io/library/busybox:stable --restart=Never -- \
  sh -c 'cat /etc/resolv.conf; echo; nslookup web.default.svc.cluster.local || true; \
         echo; wget -S -O- http://web 2>&1 | head -n 20 || true'

# 展开所有后端 IP:Port（无 jq 版）
kubectl get endpoints web -o jsonpath='{range .subsets[*]}{range .addresses[*]}{.ip}:{end}{range .ports[*]}{.port}{"\n"}{end}{end}'
```

## 13) 资源清理与保护

```bash
# 强删卡住的 Pod
kubectl delete pod <pod> --force --grace-period=0

# 保护关键资源（加注解/标签避免被误删）
kubectl annotate deploy/web safe-delete=confirm
kubectl label deploy/web protected=true
```
