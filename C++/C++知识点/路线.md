

# ✅ **【总纲：主线技能树】**

```
C → C++11 → Linux 网络栈 → 虚拟网络 → eBPF/XDP → SDN/OpenFlow → 综合项目
```

# 🟦 **模块 1：C 语言基础（1–2 周）**

### 📌 ToDo List

* [ ] 掌握 malloc/free、内存管理基础
* [ ] 学会写简单 Makefile（编译多个 .c 文件）
* [ ] 学会使用 gdb 调试简单程序

### 📌 小项目（输出物）

* [ ] 用 C 写一个 UDP Echo Server

# 🟩 **模块 2：现代 C++11（2–3 周）**

### 📌 ToDo List

* [ ] 学习 RAII、构造函数/析构函数机制
* [ ] 掌握智能指针（unique_ptr / shared_ptr）
* [ ] 掌握常用 STL（vector/map/unordered_map）
* [ ] 学 lambda、auto、range-for 现代用法
* [ ] 简单使用 std::thread（理解而非深入》

### 📌 小项目（输出物）

* [ ] C++11 写一个 mini HTTP 服务器（返回 “hello world”）
* [ ] 或 C++ 写一个端口扫描器（扫描 1-1024 端口）

# 🟥 **模块 3：Linux 网络栈（3–4 周）**

### 📌 ToDo List

* [ ] 阅读 Linux Kernel Networking（Rami Rosen）相关章节（收包路径）
* [ ] 理解 NIC → DMA → 中断 → NAPI → skb → IP → TCP 的整体路径
* [ ] 学习 softirq、ksoftirqd、poll 的作用
* [ ] 学习 Netfilter 五条链（PREROUTING / INPUT / FORWARD / OUTPUT / POSTROUTING）
* [ ] 学习 skb：字段、生命周期、clone/copy 概念
* [ ] 学习路由流程（本地目的 vs 转发路径）

### 📌 小实验（输出物）

* [ ] 画一张“收包流程图”
* [ ] 用 tcpdump 抓包对比 INPUT/FORWARD 的触发行为

---

# 🟫 **模块 4：虚拟网络（1–2 周）**

### 📌 ToDo List

* [ ] 学 network namespace 的作用（隔离网络栈）
* [ ] 学 veth pair 的作用（虚拟网线）
* [ ] 学 Linux bridge（L2 交换机）
* [ ] 学 TUN/TAP 基础（用户态虚拟网卡）
* [ ] 学少量 VXLAN 原理（可选）

### 📌 小实验（输出物）

* [ ] 用 ip netns + veth + bridge 搭一个 2 主机 + 交换机 的虚拟网络
* [ ] 用 tcpdump 抓包验证网络路径

---

# 🟨 **模块 5：eBPF / XDP（重点模块，4–6 周）**

### 📌 ToDo List（基础）

* [ ] 安装 eBPF 工具链（llvm/clang、bpftool、bcc）
* [ ] 学习 eBPF 程序类型（XDP / TC / kprobe / tracepoint）
* [ ] 学习 map 类型（ARRAY/HASH/percpu）
* [ ] 学 eBPF verifier 的基本限制（不允许循环等）
* [ ] 学 xdp_action（DROP/PASS/REDIRECT）
* [ ] 学 XDP 在驱动中的挂载点（RX path 最早层）

### 📌 ToDo List（进阶）

* [ ] 学会写 XDP 程序解析 Ethernet 头
* [ ] 解析 IPv4 头（源 IP / 目的 IP / 协议号）
* [ ] 解析 TCP / UDP 头（源端口 / 目的端口）
* [ ] 学 userspace 程序更新 map（Python or C）

### 📌 小项目（输出物）

* [ ] XDP：丢弃某个源 IP 的包
* [ ] XDP：丢弃某个端口的包
* [ ] 用户态动态更新 XDP 规则（写一个 Python/C++ CLI）
* [ ] 输出文档：XDP vs Netfilter 性能对比（简单测试即可）

# 🟧 **模块 7：综合项目（你的王牌项目，4–6 周）**

此部分是 **最重要、最能拿实习的模块**。

### 📌 ToDo List（控制面）

* [ ] 写一个 Python 的策略管理 API（增删改查规则）
* [ ] 策略结构（IP、Port、Protocol、Action）
* [ ] 策略持久化（json/sqlite 都行）

### 📌 ToDo List（OpenFlow 数据面）

* [ ] 从策略 → 生成流表项
* [ ] 下发给交换机（Ryu 控制器）
* [ ] 验证能正常阻断/放行流量

### 📌 ToDo List（eBPF 数据面）

* [ ] C 写 XDP 程序接收 map 中的规则
* [ ] 实现 L3/L4 过滤逻辑（DROP/PASS）
* [ ] Userspace 与 map 同步策略

### 📌 ToDo List（策略同步）

* [ ] 写一个 Python/C++ 程序从控制面拉取策略
* [ ] 转换成：

  * OpenFlow 流表项
  * eBPF map 更新语句
* [ ] 同步下发两个数据面

### 📌 输出物（最终成果）

* [ ] 双数据面防火墙（OpenFlow + XDP）
* [ ] 控制面（策略管理）
* [ ] Mininet + namespace 的测试文档
* [ ] 架构图（控制面-数据面联动）
* [ ] 抓包截图（验证规则生效）
* [ ] 读我文档 README（含运行步骤）
