## 24.0 继承简介

### 什么是继承？
继承是面向对象编程的四大特性之一（封装、继承、多态、抽象），它允许一个类（派生类）基于另一个类（基类）构建，从而复用基类的代码和功能。

### 继承的核心概念
- **基类（Base Class）**：被继承的类，也称为父类或超类
- **派生类（Derived Class）**：继承自基类的类，也称为子类
- **"是一个"（is-a）关系**：派生类是基类的一种特殊类型
- **代码复用**：避免重复编写相同的代码

### 继承的类型
```cpp
// 1. 单继承：一个派生类只有一个基类
class Derived : public Base {};

// 2. 多重继承：一个派生类有多个基类
class Derived : public Base1, public Base2 {};

// 3. 多层继承：派生类本身也可以作为基类
class Base {};
class Intermediate : public Base {};
class Derived : public Intermediate {};
```

### 为什么要使用继承？
1. **代码复用**：避免重复代码
2. **可扩展性**：易于添加新功能
3. **维护性**：修改基类可以影响所有派生类
4. **多态性**：通过虚函数实现运行时多态

## 24.1 基本继承

### 继承的基本语法
```cpp
// 基类
class Animal {
protected:
    std::string name;
    int age;
    
public:
    Animal(const std::string& n, int a) : name(n), age(a) {}
    
    void eat() {
        std::cout << name << " is eating." << std::endl;
    }
    
    void sleep() {
        std::cout << name << " is sleeping." << std::endl;
    }
};

// 派生类
class Dog : public Animal {  // 公有继承
private:
    std::string breed;
    
public:
    Dog(const std::string& n, int a, const std::string& b) 
        : Animal(n, a), breed(b) {}
    
    void bark() {
        std::cout << name << " is barking!" << std::endl;
    }
    
    void displayInfo() {
        std::cout << name << " is a " << breed 
                  << ", age " << age << std::endl;
    }
};
```

### 继承的可访问性
```cpp
class Base {
public:
    int publicVar;
    
protected:
    int protectedVar;
    
private:
    int privateVar;
};

// 公有继承
class PublicDerived : public Base {
    // publicVar 保持 public
    // protectedVar 保持 protected
    // privateVar 不可访问
};

// 保护继承
class ProtectedDerived : protected Base {
    // publicVar 变为 protected
    // protectedVar 保持 protected
    // privateVar 不可访问
};

// 私有继承
class PrivateDerived : private Base {
    // publicVar 变为 private
    // protectedVar 变为 private
    // privateVar 不可访问
};
```

### 成员访问权限表
| 基类中的访问权限 | 继承类型 | 派生类中的访问权限 |
|-----------------|----------|-------------------|
| public | public | public |
| protected | public | protected |
| private | public | 不可访问 |
| public | protected | protected |
| protected | protected | protected |
| private | protected | 不可访问 |
| public | private | private |
| protected | private | private |
| private | private | 不可访问 |

## 24.2 派生类的构造顺序

### 构造顺序的规则
当创建派生类对象时，构造函数的调用顺序是：

1. **基类构造函数**（如果有多个基类，按继承列表顺序）
2. **成员对象的构造函数**（按声明顺序）
3. **派生类自身的构造函数体**

### 示例演示
```cpp
#include <iostream>
#include <string>

class Base {
public:
    Base() {
        std::cout << "Base constructor called" << std::endl;
    }
    
    Base(int x) {
        std::cout << "Base(int) constructor called with " << x << std::endl;
    }
    
    ~Base() {
        std::cout << "Base destructor called" << std::endl;
    }
};

class Member {
    std::string name;
    
public:
    Member(const std::string& n) : name(n) {
        std::cout << "Member constructor called for " << name << std::endl;
    }
    
    ~Member() {
        std::cout << "Member destructor called for " << name << std::endl;
    }
};

class Derived : public Base {
private:
    Member m1{"First"};
    Member m2{"Second"};
    int value;
    
public:
    Derived() : Base(100), value(50) {
        std::cout << "Derived constructor called" << std::endl;
    }
    
    Derived(int v) : Base(v * 2), value(v) {
        std::cout << "Derived(int) constructor called with " << v << std::endl;
    }
    
    ~Derived() {
        std::cout << "Derived destructor called" << std::endl;
    }
};

int main() {
    std::cout << "Creating Derived object:" << std::endl;
    Derived d1;
    std::cout << "\nCreating Derived object with parameter:" << std::endl;
    Derived d2(25);
    std::cout << "\nObjects going out of scope:" << std::endl;
    
    return 0;
}
```

**输出结果：**
```
Creating Derived object:
Base(int) constructor called with 100
Member constructor called for First
Member constructor called for Second
Derived constructor called

Creating Derived object with parameter:
Base(int) constructor called with 50
Member constructor called for First
Member constructor called for Second
Derived(int) constructor called with 25

Objects going out of scope:
Derived destructor called
Member destructor called for Second
Member destructor called for First
Base destructor called
Derived destructor called
Member destructor called for Second
Member destructor called for First
Base destructor called
```

### 多层继承的构造顺序
```cpp
class A {
public:
    A() { std::cout << "A constructed" << std::endl; }
    ~A() { std::cout << "A destroyed" << std::endl; }
};

class B : public A {
public:
    B() { std::cout << "B constructed" << std::endl; }
    ~B() { std::cout << "B destroyed" << std::endl; }
};

class C : public B {
public:
    C() { std::cout << "C constructed" << std::endl; }
    ~C() { std::cout << "C destroyed" << std::endl; }
};

// 构造顺序: A -> B -> C
// 析构顺序: C -> B -> A
```

## 24.3 派生类的构造函数与初始化

### 基类构造函数的调用
派生类不能直接初始化继承的基类成员，必须通过调用基类构造函数来完成。

```cpp
class Base {
protected:
    int id;
    const int version;
    
public:
    Base(int i, int v) : id(i), version(v) {
        std::cout << "Base constructed with id=" << id 
                  << ", version=" << version << std::endl;
    }
};

class Derived : public Base {
private:
    double value;
    
public:
    // 错误：不能在派生类中直接初始化基类成员
    // Derived(double v, int i) : value(v), id(i) {}
    
    // 正确：通过调用基类构造函数
    Derived(double v, int i, int ver) 
        : Base(i, ver),  // 必须首先调用基类构造函数
          value(v)       // 然后初始化派生类成员
    {
        std::cout << "Derived constructed with value=" << value << std::endl;
    }
    
    // 如果基类有默认构造函数，可以不显式调用
    Derived(double v) : value(v) {
        // 隐式调用 Base() 默认构造函数
        std::cout << "Derived constructed with default base" << std::endl;
    }
};
```

### 初始化列表的顺序
**重要**：初始化顺序由类中成员的声明顺序决定，而不是初始化列表中的顺序。

```cpp
class Example {
private:
    int a;  // 声明顺序 1
    int b;  // 声明顺序 2
    int c;  // 声明顺序 3
    
public:
    // 危险：初始化列表顺序与声明顺序不同
    Example(int x) 
        : c{x},     // 实际初始化顺序：a -> b -> c
          b{a * 2}, // 错误：a 还未初始化！
          a{x}      // 这里才初始化 a
    {}
    
    // 正确：按照声明顺序
    Example(int x) 
        : a{x},     // 1. 先初始化 a
          b{a * 2}, // 2. 使用 a 初始化 b
          c{b + 1}  // 3. 使用 b 初始化 c
    {}
};
```

### 委托构造函数
```cpp
class Base {
protected:
    int id;
    std::string name;
    
public:
    // 主构造函数
    Base(int i, const std::string& n) : id(i), name(n) {
        std::cout << "Base main constructor" << std::endl;
    }
    
    // 委托构造函数
    Base() : Base(0, "Unnamed") {
        std::cout << "Base default constructor" << std::endl;
    }
    
    Base(int i) : Base(i, "Unknown") {
        std::cout << "Base(int) constructor" << std::endl;
    }
};
```

## 24.4 继承和访问说明符

### 三种访问说明符的作用
```cpp
class Example {
public:      // 公有：任何地方都可以访问
    int publicVar;
    
protected:   // 保护：类内和派生类中可以访问
    int protectedVar;
    
private:     // 私有：只能在类内访问
    int privateVar;
    
public:
    void testAccess() {
        publicVar = 1;      // ✅ 可以访问
        protectedVar = 2;   // ✅ 可以访问
        privateVar = 3;     // ✅ 可以访问
    }
};

class Derived : public Example {
public:
    void testDerivedAccess() {
        publicVar = 1;      // ✅ 可以访问
        protectedVar = 2;   // ✅ 可以访问
        // privateVar = 3;  // ❌ 错误：不能访问基类的私有成员
    }
};

int main() {
    Example obj;
    obj.publicVar = 1;      // ✅ 可以访问
    // obj.protectedVar = 2; // ❌ 错误：不能访问保护成员
    // obj.privateVar = 3;   // ❌ 错误：不能访问私有成员
}
```

### 继承类型的访问控制
```cpp
class Base {
public:
    int a;
protected:
    int b;
private:
    int c;
};

// 公有继承
class PublicDerived : public Base {
    // a 保持 public
    // b 保持 protected
    // c 不可访问
};

// 保护继承
class ProtectedDerived : protected Base {
    // a 变为 protected
    // b 保持 protected
    // c 不可访问
};

// 私有继承
class PrivateDerived : private Base {
    // a 变为 private
    // b 变为 private
    // c 不可访问
};
```

### 使用 using 改变访问权限
```cpp
class Base {
public:
    void publicFunc() {}
protected:
    void protectedFunc() {}
};

class Derived : private Base {  // 私有继承
public:
    // 将基类的 protectedFunc 提升为 public
    using Base::protectedFunc;
    
    // 注意：不能提升不可访问的成员
    // using Base::privateFunc;  // 错误：基类没有此成员
};

int main() {
    Derived d;
    d.protectedFunc();  // ✅ 可以访问，因为被提升为 public
    // d.publicFunc();  // ❌ 错误：仍然是 private
}
```

## 24.5 向派生类添加新功能

### 添加新成员变量
```cpp
class Vehicle {
protected:
    std::string make;
    std::string model;
    int year;
    
public:
    Vehicle(const std::string& m, const std::string& mod, int y)
        : make(m), model(mod), year(y) {}
    
    void displayInfo() const {
        std::cout << year << " " << make << " " << model;
    }
};

class Car : public Vehicle {
private:
    int doors;        // 新增成员
    std::string fuelType;  // 新增成员
    
public:
    Car(const std::string& m, const std::string& mod, int y, 
        int d, const std::string& fuel)
        : Vehicle(m, mod, y), doors(d), fuelType(fuel) {}
    
    // 新增功能
    void displayCarInfo() const {
        displayInfo();  // 调用基类方法
        std::cout << ", " << doors << " doors, " 
                  << fuelType << " fuel" << std::endl;
    }
    
    int getDoors() const { return doors; }
    std::string getFuelType() const { return fuelType; }
};
```

### 添加新成员函数
```cpp
class BankAccount {
protected:
    double balance;
    
public:
    BankAccount(double initial = 0.0) : balance(initial) {}
    
    void deposit(double amount) {
        if (amount > 0) {
            balance += amount;
        }
    }
    
    virtual bool withdraw(double amount) {
        if (amount > 0 && amount <= balance) {
            balance -= amount;
            return true;
        }
        return false;
    }
    
    double getBalance() const { return balance; }
};

class SavingsAccount : public BankAccount {
private:
    double interestRate;
    
public:
    SavingsAccount(double initial, double rate)
        : BankAccount(initial), interestRate(rate) {}
    
    // 新增功能
    void addInterest() {
        double interest = balance * interestRate / 100.0;
        deposit(interest);
    }
    
    double getInterestRate() const { return interestRate; }
    
    // 重写基类功能
    bool withdraw(double amount) override {
        if (amount > 0 && amount <= balance && amount <= 1000) {
            balance -= amount;
            return true;
        }
        return false;
    }
};
```

### 扩展基类功能
```cpp
class Employee {
protected:
    std::string name;
    double salary;
    
public:
    Employee(const std::string& n, double s) : name(n), salary(s) {}

        return salary;  // 基本工资

        std::cout << "Employee: " << name

    }
};

class Manager : public Employee {

    double bonus;
    
public:
    Manager(const std::string& n, double s, double b)
        : Employee(n, s), bonus(b) {}

        return salary + bonus;  // 基本工资 + 奖金
    }
    
    // 扩展显示信息功能
    void displayInfo() const override {
        Employee::displayInfo();  // 调用基类方法
        std::cout << "  Bonus: $" << bonus 
                  << ", Total: $" << calculatePay() << std::endl;
    }
    
    // 新增管理功能
    void conductMeeting() {
        std::cout << name << " is conducting a meeting." << std::endl;
    }
};
```

## 24.6 调用继承的函数与重写行为

### 函数重写（Override）
```cpp
class Animal {
public:
    virtual void makeSound() const {
        std::cout << "Animal makes a sound" << std::endl;
    }
    
    void eat() {
        std::cout << "Animal is eating" << std::endl;
    }
};

class Dog : public Animal {
public:
    // 重写虚函数
    void makeSound() const override {
        std::cout << "Dog barks: Woof! Woof!" << std::endl;
    }
    
    // 隐藏基类的非虚函数（不推荐）
    void eat() {
        std::cout << "Dog is eating dog food" << std::endl;
    }
};
```

### override 和 final 关键字
```cpp
class Base {
public:
    virtual void func1() {
        std::cout << "Base::func1()" << std::endl;
    }
    
    virtual void func2() {
        std::cout << "Base::func2()" << std::endl;
    }
    
    // 最终函数，不能被派生类重写
    virtual void finalFunc() final {
        std::cout << "This cannot be overridden" << std::endl;
    }
};

class Derived : public Base {
public:
    // 明确表示这是重写
    void func1() override {
        std::cout << "Derived::func1()" << std::endl;
    }
    
    // 错误：拼写错误会被编译器捕获
    // void Func1() override {}  // 错误：没有要重写的函数
    
    // 最终派生类
    void func2() override final {
        std::cout << "Derived::func2() cannot be further overridden" << std::endl;
    }
    
    // 错误：不能重写final函数
    // void finalFunc() override {}  // 错误
};

class FurtherDerived : public Derived {
public:
    // 可以重写 func1
    void func1() override {
        std::cout << "FurtherDerived::func1()" << std::endl;
    }
    
    // 错误：不能重写final函数
    // void func2() override {}  // 错误
};
```

### 调用基类版本
```cpp
class Base {
public:
    void display() {
        std::cout << "Base display" << std::endl;
    }
    
    virtual void show() {
        std::cout << "Base show" << std::endl;
    }
};

class Derived : public Base {
public:
    void display() {  // 隐藏基类版本
        Base::display();  // 显式调用基类版本
        std::cout << "Derived display" << std::endl;
    }
    
    void show() override {
        Base::show();  // 调用基类虚函数
        std::cout << "Derived show" << std::endl;
    }
};
```

### 纯虚函数和抽象类
```cpp
// 抽象基类
class Shape {
public:
    virtual double area() const = 0;  // 纯虚函数
    virtual double perimeter() const = 0;
    
    virtual void display() const {
        std::cout << "Shape: ";
    }
    
    // 可以有具体实现的方法
    void printArea() const {
        std::cout << "Area: " << area() << std::endl;
    }
    
    virtual ~Shape() = default;  // 虚析构函数
};

// 具体类
class Circle : public Shape {
private:
    double radius;
    
public:
    Circle(double r) : radius(r) {}
    
    double area() const override {
        return 3.14159 * radius * radius;
    }
    
    double perimeter() const override {
        return 2 * 3.14159 * radius;
    }
    
    void display() const override {
        Shape::display();
        std::cout << "Circle with radius " << radius << std::endl;
    }
};
```

## 24.7 隐藏继承的功能

### 名字隐藏（Name Hiding）
```cpp
class Base {
public:
    void func() {
        std::cout << "Base::func()" << std::endl;
    }
    
    void func(int x) {
        std::cout << "Base::func(int) with " << x << std::endl;
    }
    
    virtual void action() {
        std::cout << "Base::action()" << std::endl;
    }
};

class Derived : public Base {
public:
    // 隐藏基类的所有func版本
    void func() {
        std::cout << "Derived::func()" << std::endl;
    }
    
    // 不重写，只是新增
    void action(double d) {
        std::cout << "Derived::action(double) with " << d << std::endl;
    }
};

int main() {
    Derived d;
    d.func();        // ✅ 调用 Derived::func()
    // d.func(5);    // ❌ 错误：Base::func(int) 被隐藏
    d.Base::func(5); // ✅ 显式调用基类版本
    
    d.action();      // ✅ 调用继承的 Base::action()
    d.action(3.14);  // ✅ 调用 Derived::action(double)
    
    Base* b = &d;
    b->func(10);     // ✅ 通过基类指针调用
    b->action();     // ✅ 多态调用 Base::action()
    
    return 0;
}
```

### 使用 using 声明解决名字隐藏
```cpp
class Base {
public:
    void func() {
        std::cout << "Base::func()" << std::endl;
    }
    
    void func(int x) {
        std::cout << "Base::func(int) with " << x << std::endl;
    }
    
    void func(double x) {
        std::cout << "Base::func(double) with " << x << std::endl;
    }
};

class Derived : public Base {
public:
    // 将基类的func引入当前作用域
    using Base::func;
    
    // 添加自己的版本
    void func(const std::string& s) {
        std::cout << "Derived::func(string) with " << s << std::endl;
    }
};

int main() {
    Derived d;
    d.func();           // ✅ Base::func()
    d.func(5);          // ✅ Base::func(int)
    d.func(3.14);       // ✅ Base::func(double)
    d.func("hello");    // ✅ Derived::func(string)
    
    return 0;
}
```

### 隐藏与重写的区别
```cpp
class Base {
public:
    void nonVirtual() {
        std::cout << "Base::nonVirtual()" << std::endl;
    }
    
    virtual void isVirtual() {
        std::cout << "Base::isVirtual()" << std::endl;
    }
};

class Derived : public Base {
public:
    // 隐藏，不是重写
    void nonVirtual() {
        std::cout << "Derived::nonVirtual()" << std::endl;
    }
    
    // 重写
    void isVirtual() override {
        std::cout << "Derived::isVirtual()" << std::endl;
    }
};

int main() {
    Derived d;
    Base* b = &d;
    
    // 非虚函数：静态绑定
    d.nonVirtual();     // Derived::nonVirtual()
    b->nonVirtual();    // Base::nonVirtual() ← 注意！
    
    // 虚函数：动态绑定
    d.isVirtual();      // Derived::isVirtual()
    b->isVirtual();     // Derived::isVirtual() ← 多态！
    
    return 0;
}
```

## 24.8 多重继承

### 基本多重继承
```cpp
class Printable {
public:
    virtual void print() const = 0;
    virtual ~Printable() = default;
};

class Drawable {
public:
    virtual void draw() const = 0;
    virtual ~Drawable() = default;
};

class Savable {
public:
    virtual void save(const std::string& filename) const = 0;
    virtual ~Savable() = default;
};

// 多重继承
class Document : public Printable, public Drawable, public Savable {
private:
    std::string content;
    
public:
    Document(const std::string& c) : content(c) {}
    
    void print() const override {
        std::cout << "Printing: " << content << std::endl;
    }
    
    void draw() const override {
        std::cout << "Drawing document" << std::endl;
    }
```

### 虚继承解决菱形问题
```cpp
class A {
public:
    int value;
    
    A(int v = 0) : value(v) {
        std::cout << "A constructed with " << value << std::endl;
    }
    
    void show() {
        std::cout << "A::show() with value = " << value << std::endl;
    }
};

// 虚继承
class B : virtual public A {
public:
    B(int v) : A(v) {
        std::cout << "B constructed" << std::endl;
    }
};

// 虚继承
class C : virtual public A {
public:
    C(int v) : A(v) {
        std::cout << "C constructed" << std::endl;
    }
};

// 现在D只有一个A的副本
class D : public B, public C {
public:
    // 虚基类由最派生类初始化
    D(int bVal, int cVal, int dVal) 
        : A(dVal),  // 初始化虚基类
          B(bVal),  // 传递给A的参数被忽略
          C(cVal)   // 传递给A的参数被忽略
    {
        std::cout << "D constructed" << std::endl;
    }
    
    void test() {
        value = 100;  // ✅ 没有歧义
        show();       // ✅ 没有歧义
    }
};
```

## 24.9 第24章总结

### 继承的核心要点
1. **代码复用**：继承是代码复用的重要机制
2. **"是一个"关系**：派生类是基类的特殊类型
3. **访问控制**：public、protected、private继承控制成员可见性
4. **构造顺序**：基类→成员→派生类构造函数体
5. **多态性**：通过虚函数实现运行时多态

### 继承的最佳实践
1. **使用公有继承表示"是一个"关系**
2. **总是将析构函数声明为virtual（当类中有虚函数时）**
3. **使用override关键字明确重写意图**
4. **避免过度使用多重继承**
5. **优先使用组合而非继承（除非确定是"是一个"关系）**

### 何时使用继承？
1. 存在清晰的"是一个"关系
2. 需要多态行为
3. 基类代码确实可以在派生类中复用
4. 派生类需要扩展而非修改基类功能

### 何时避免继承？
1. 只是需要复用实现，没有"是一个"关系（使用组合）
2. 派生类需要大量修改基类行为
3. 基类不是为继承设计的
4. 可能导致复杂的继承层次

### 1. 虚析构函数
```cpp
class Base {
public:
    Base() { std::cout << "Base constructor" << std::endl; }
    
    // 虚析构函数确保正确释放资源
    virtual ~Base() { 
        std::cout << "Base destructor" << std::endl; 
    }
    
    virtual void doSomething() {
        std::cout << "Base::doSomething()" << std::endl;
    }
};

class Derived : public Base {
private:
    int* data;
    
public:
    Derived() : data(new int[100]) {
        std::cout << "Derived constructor" << std::endl;
    }
    
    ~Derived() override {
        delete[] data;
        std::cout << "Derived destructor" << std::endl;
    }
    
    void doSomething() override {
        std::cout << "Derived::doSomething()" << std::endl;
    }
};

int main() {
    Base* ptr = new Derived();
    ptr->doSomething();
    delete ptr;  // ✅ 正确调用 Derived 的析构函数
    
    return 0;
}
```

### 4. 接口继承 vs 实现继承
```cpp
// 接口继承（抽象类）
class ICloneable {
public:
    virtual std::unique_ptr<ICloneable> clone() const = 0;
    virtual ~ICloneable() = default;
};

// 实现继承
class Shape : public ICloneable {
protected:
    std::string color;
    
public:
    Shape(const std::string& c) : color(c) {}
    
    virtual double area() const = 0;
    
    std::unique_ptr<ICloneable> clone() const override = 0;
    
    void setColor(const std::string& c) {
        color = c;
    }
};

class Circle : public Shape {
    double radius;
    
public:
    Circle(const std::string& c, double r) : Shape(c), radius(r) {}
    
    double area() const override {
        return 3.14159 * radius * radius;
    }
    
    std::unique_ptr<ICloneable> clone() const override {
        return std::make_unique<Circle>(*this);
    }
};
```
