### **编译时多态与运行时多态**

在 C++ 中，**多态**（Polymorphism）可以分为**编译时多态**和**运行时多态**。两者有不同的实现机制，分别满足不同的需求。

* **运行时多态**（Runtime Polymorphism）：通过虚函数实现。
* **编译时多态**（Compile-time Polymorphism）：主要通过 **模板** 和 **函数重载**（或运算符重载）实现。

我们将详细讲解两者之间的区别以及编译时多态如何实现。

---

### 1. **编译时多态（Compile-time Polymorphism）**

编译时多态是指在编译阶段就决定了调用哪个函数或哪个操作，这种多态通常不依赖于运行时的对象类型。主要有两种形式：

* **函数重载（Function Overloading）**
* **模板（Templates）**

#### 1.1 **函数重载（Function Overloading）**

函数重载是指定义多个同名的函数，但它们具有不同的参数列表（参数数量或类型不同）。编译器在编译时根据传递给函数的参数类型或数量来选择具体调用哪个版本的函数。

**示例：**

```cpp
#include <iostream>
using namespace std;

class Printer {
public:
    void print(int i) {
        cout << "Printing int: " << i << endl;
    }

    void print(double d) {
        cout << "Printing double: " << d << endl;
    }

    void print(const string& str) {
        cout << "Printing string: " << str << endl;
    }
};

int main() {
    Printer printer;
    printer.print(5);        // 调用 print(int)
    printer.print(3.14);     // 调用 print(double)
    printer.print("Hello");  // 调用 print(string)

    return 0;
}
```

**输出：**

```
Printing int: 5
Printing double: 3.14
Printing string: Hello
```

* 在上面的例子中，`print()` 函数有多个版本，它们根据传入的参数类型进行选择。
* **编译时多态**的选择是由编译器根据实际传入的参数类型决定的。

#### 1.2 **模板（Templates）**

模板是 C++ 提供的一种强大的特性，它允许你编写能够与不同数据类型一起工作的代码。模板实现了**编译时多态**，因为模板的实例化是在编译时完成的，而不是在运行时。

**示例：**

```cpp
#include <iostream>
using namespace std;

template <typename T>
void print(T value) {
    cout << "Printing: " << value << endl;
}

int main() {
    print(5);        // int 类型
    print(3.14);     // double 类型
    print("Hello");  // const char* 类型

    return 0;
}
```

**输出：**

```
Printing: 5
Printing: 3.14
Printing: Hello
```

* 这里的 `print` 函数是一个模板函数，能够接受任何类型的参数。编译器会根据传入的具体类型生成相应的代码实例。
* 这种多态性是在编译时完成的，即 **编译时多态**。

#### 1.3 **模板与重载的区别**

* **模板**：编译时根据参数的类型推导出具体的实现代码，适用于任何类型。
* **函数重载**：编译时根据函数的参数数量或类型选择匹配的函数版本，适用于不同的参数组合。

### 2. **运行时多态（Runtime Polymorphism）**

运行时多态是指在运行时根据对象的实际类型来决定调用哪个函数。这种多态依赖于 **虚函数** 和 **继承** 机制。我们已经在前面的讨论中详细介绍过，运行时多态通过**虚函数**来实现。

#### 2.1 **虚函数的工作机制**

* **虚函数**：函数在基类中声明为 `virtual`，然后在派生类中可以进行重写。当通过基类指针或引用调用该虚函数时，C++ 会根据对象的实际类型来调用派生类中的函数实现，而不是基类的实现。这个过程被称为 **动态绑定** 或 **运行时多态**。

**示例：**

```cpp
#include <iostream>
using namespace std;

class Base {
public:
    virtual void show() { 
        cout << "Base class show" << endl; 
    }
};

class Derived : public Base {
public:
    void show() override { 
        cout << "Derived class show" << endl; 
    }
};

int main() {
    Base* basePtr;
    Derived derivedObj;
    basePtr = &derivedObj;

    basePtr->show();  // 运行时多态：调用 Derived 类的 show() 方法
    return 0;
}
```

**输出：**

```
Derived class show
```

* 这里的 `show()` 是一个虚函数，`basePtr` 是基类 `Base` 的指针，指向了派生类 `Derived` 对象。由于 `show()` 是虚函数，C++ 会在运行时根据 `basePtr` 实际指向的对象类型（`Derived`）来调用 `Derived` 类的 `show()` 方法。

### 3. **总结：编译时多态与运行时多态**

* **编译时多态**：发生在编译时，主要通过 **函数重载** 和 **模板** 来实现。编译器在编译期间根据参数类型或模板实例化来决定调用哪个函数或生成哪个函数实例。典型的实现有：

  * **函数重载**：同名函数根据参数类型或数量的不同来进行区分。
  * **模板**：根据类型参数的不同生成不同的代码。

* **运行时多态**：发生在程序运行时，通过 **虚函数** 和 **继承** 来实现。基类指针或引用指向派生类对象时，虚函数会在运行时动态绑定到实际的派生类实现，允许不同类型的对象共享相同的接口。

**编译时多态**通常是**性能更好的选择**，因为它在编译时就确定了调用哪个函数，不涉及运行时的开销（如虚函数表和动态绑定）。

而**运行时多态**提供了更强的灵活性，允许在运行时根据对象的实际类型来调用相应的方法，适用于需要接口统一、但实现多样化的场景。
