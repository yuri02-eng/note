在 CSS 中，`padding` 和 `margin` 设置负值的行为和含义完全不同：

### 1. **负值 `margin`（有效且常用）**
   - **含义**：负边距会使元素向指定方向收缩或偏移，**突破容器边界**，常用于微调布局。
   - **效果**：
     - `margin-left: -10px;` → 元素向左移动 10px（可能覆盖左侧内容）。
     - `margin-top: -20px;` → 元素向上移动 20px（可能覆盖上方内容）。
     - `margin-right: -15px;` → 元素右侧边界向内收缩 15px，后续元素可更靠近。
     - `margin-bottom: -5px;` → 元素下方空间减少 5px，下方元素会向上移动。
   - **应用场景**：
     - 实现重叠效果（如卡片叠放）。
     - 消除默认间距（如列表项或网格间隙）。
     - 多栏布局中对齐（如圣杯布局中调整位置）。
   - **示例**：
     ```css
     .box {
       margin-left: -20px; /* 向左溢出容器 20px */
     }
     ```

### 2. **负值 `padding`（无效且被忽略）**
   - **含义**：`padding` **不支持负值**！浏览器会直接忽略负的 `padding` 设置，视作 `padding: 0;`。
   - **原因**：内边距的作用是增加元素内部空间，负值（向内挤压内容）不符合逻辑，CSS 规范明确定义其无效。
   - **替代方案**：
     - 如需向内收缩空间，应调整内容尺寸（如 `width`/`height`）。
     - 使用 `transform: scale()` 缩放内容。
   - **示例**：
     ```css
     .box {
       padding: -10px; /* 无效！实际效果等同于 padding: 0; */
     }
     ```

---

### 关键总结
| 属性     | 支持负值？ | 行为                           | 典型用途               |
|----------|------------|-------------------------------|-----------------------|
| `margin` | ✅ 是       | 移动元素/收缩边界，可覆盖其他内容 | 布局微调、重叠效果     |
| `padding`| ❌ 否       | 被忽略，等同于 `0`             | 无（需用其他方法替代） |

### 注意事项
- **负 `margin` 的副作用**：过度使用可能导致内容重叠、布局混乱，需谨慎调试。
- **现代布局替代**：Flexbox / Grid 布局可减少对负 `margin` 的依赖（如 `gap` 属性替代间距调整）。

合理使用负 `margin` 能解决特定布局问题，但务必避免负 `padding`（无效）。
