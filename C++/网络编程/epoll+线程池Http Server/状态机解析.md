# HTTP请求解析流程详细文档

## 1. 整体架构概述

### 1.1 解析流程总览
```
客户端请求 → 读取数据 → 行解析 → 状态机解析 → 处理请求 → 生成响应
    ↓          ↓         ↓         ↓          ↓         ↓
 socket    读缓冲区   按行分割   有限状态机   文件操作   写缓冲区
```

### 1.2 核心组件关系
```
http_conn类
├── 数据读取层 (read())
├── 协议解析层 (process_read())
│   ├── 行解析器 (parse_line())
│   └── 状态机解析 (parse_request_line(), parse_headers(), parse_content())
├── 业务处理层 (do_request())
└── 响应生成层 (process_write(), write())
```

## 2. 详细解析流程

### 2.1 数据读取阶段

#### 2.1.1 读取入口 - `process()` 方法
```cpp
void http_conn::process()
{
    // 步骤1: 读取并解析HTTP请求
    HTTP_CODE read_ret = process_read();
    
    // 步骤2: 如果请求不完整，等待更多数据
    if (read_ret == NO_REQUEST) {
        modfd(m_epollfd, m_sockfd, EPOLLIN);
        return;
    }
    
    // 步骤3: 生成响应
    bool write_ret = process_write(read_ret);
    
    // 步骤4: 准备发送响应
    modfd(m_epollfd, m_sockfd, EPOLLOUT);
}
```

#### 2.1.2 数据读取 - `read()` 方法
```cpp
bool http_conn::read()
{
    // 边缘触发(ET)模式下的非阻塞读取循环
    while (true) {
        bytes_read = recv(m_sockfd, m_read_buf + m_read_idx, 
                         READ_BUFFER_SIZE - m_read_idx, 0);
        
        if (bytes_read == -1) {
            if (errno == EAGAIN || errno == EWOULDBLOCK) {
                break;  // 非阻塞IO的正常情况：没有数据可读了
            }
            return false;  // 真正的错误
        } else if (bytes_read == 0) {
            return false;  // 对端关闭连接
        }
        
        m_read_idx += bytes_read;  // 更新已读取数据长度
    }
    return true;
}
```

### 2.2 行解析阶段

#### 2.2.1 行解析状态机
```cpp
http_conn::LINE_STATUS http_conn::parse_line()
{
    // 遍历已读取的数据，查找行结束符\r\n
    for (; m_checked_idx < m_read_idx; ++m_checked_idx) {
        char temp = m_read_buf[m_checked_idx];
        
        if (temp == '\r') {
            // 检查是否完整的\r\n
            if ((m_checked_idx + 1) == m_read_idx) {
                return LINE_OPEN;  // 数据不完整，需要继续读取
            } else if (m_read_buf[m_checked_idx + 1] == '\n') {
                // 找到完整行，替换为字符串结束符
                m_read_buf[m_checked_idx++] = '\0';
                m_read_buf[m_checked_idx++] = '\0';
                return LINE_OK;
            }
            return LINE_BAD;  // 格式错误
        } else if (temp == '\n') {
            // 处理可能的非标准行结束符
            if ((m_checked_idx > 1) && (m_read_buf[m_checked_idx - 1] == '\r')) {
                m_read_buf[m_checked_idx - 1] = '\0';
                m_read_buf[m_checked_idx++] = '\0';
                return LINE_OK;
            }
            return LINE_BAD;
        }
    }
    return LINE_OPEN;  // 需要更多数据
}
```

#### 2.2.2 行解析流程图
```
开始解析行
    ↓
遍历已读数据缓冲区
    ↓
检查每个字符:
├── 如果是'\r':
│   ├── 如果下一个字符是'\n' → 找到完整行 → 返回LINE_OK
│   ├── 如果是缓冲区末尾 → 需要更多数据 → 返回LINE_OPEN  
│   └── 其他情况 → 格式错误 → 返回LINE_BAD
├── 如果是'\n':
│   ├── 如果前一个字符是'\r' → 找到完整行 → 返回LINE_OK
│   └── 其他情况 → 格式错误 → 返回LINE_BAD
└── 其他字符 → 继续检查下一个字符
```

### 2.3 状态机解析阶段

#### 2.3.1 主解析循环 - `process_read()` 方法
```cpp
http_conn::HTTP_CODE http_conn::process_read()
{
    LINE_STATUS line_status = LINE_OK;
    HTTP_CODE ret = NO_REQUEST;
    char *text = 0;

    // 主解析循环：逐行解析HTTP请求
    while (((m_check_state == CHECK_STATE_CONTENT) && (line_status == LINE_OK)) || 
           ((line_status = parse_line()) == LINE_OK)) {
        
        text = get_line();  // 获取当前解析的行
        m_start_line = m_checked_idx;  // 记录下一行起始位置
        
        // 根据当前状态机状态进行相应处理
        switch (m_check_state) {
        case CHECK_STATE_REQUESTLINE:  // 解析请求行
            ret = parse_request_line(text);
            if (ret == BAD_REQUEST) return BAD_REQUEST;
            break;
            
        case CHECK_STATE_HEADER:  // 解析头部
            ret = parse_headers(text);
            if (ret == BAD_REQUEST) return BAD_REQUEST;
            else if (ret == GET_REQUEST) return do_request();
            break;
            
        case CHECK_STATE_CONTENT:  // 解析内容体
            ret = parse_content(text);
            if (ret == GET_REQUEST) return do_request();
            line_status = LINE_OPEN;  // 内容体需要特殊处理
            break;
            
        default:
            return INTERNAL_ERROR;
        }
    }
    
    return NO_REQUEST;  // 请求不完整，需要继续读取
}
```

#### 2.3.2 请求行解析 - `parse_request_line()`
```cpp
HTTP_CODE http_conn::parse_request_line(char *text)
{
    // 示例请求行: "GET /index.html HTTP/1.1"
    
    // 1. 分离方法和URL
    m_url = strpbrk(text, " \t");  // 查找第一个空格或制表符
    if (!m_url) return BAD_REQUEST;
    *m_url++ = '\0';  // 截断方法部分
    
    // 2. 解析HTTP方法
    char *method = text;
    if (strcasecmp(method, "GET") == 0) {
        m_method = GET;
    } else {
        return BAD_REQUEST;  // 只支持GET方法
    }
    
    // 3. 分离URL和版本号
    m_url += strspn(m_url, " \t");  // 跳过空白
    m_version = strpbrk(m_url, " \t");  // 查找版本号起始位置
    if (!m_version) return BAD_REQUEST;
    *m_version++ = '\0';  // 截断URL部分
    m_version += strspn(m_version, " \t");  // 跳过空白
    
    // 4. 验证HTTP版本
    if (strcasecmp(m_version, "HTTP/1.1") != 0) {
        return BAD_REQUEST;  // 只支持HTTP/1.1
    }
    
    // 5. 处理URL格式（支持http://前缀）
    if (strncasecmp(m_url, "http://", 7) == 0) {
        m_url += 7;
        m_url = strchr(m_url, '/');  // 定位路径开始
    }
    
    // 6. URL验证
    if (!m_url || m_url[0] != '/') {
        return BAD_REQUEST;
    }
    
    // 状态转移：下一步解析头部
    m_check_state = CHECK_STATE_HEADER;
    return NO_REQUEST;
}
```

#### 2.3.3 头部解析 - `parse_headers()`
```cpp
HTTP_CODE http_conn::parse_headers(char *text)
{
    // 空行表示头部结束
    if (text[0] == '\0') {
        if (m_method == HEAD) {
            return GET_REQUEST;  // HEAD方法不需要内容体
        }
        if (m_content_length != 0) {
            m_check_state = CHECK_STATE_CONTENT;  // 有内容体需要解析
            return NO_REQUEST;
        }
        return GET_REQUEST;  // 获得完整请求
    }
    
    // 解析具体头部字段
    else if (strncasecmp(text, "Connection:", 11) == 0) {
        text += 11;
        text += strspn(text, " \t");
        if (strcasecmp(text, "keep-alive") == 0) {
            m_linger = true;  // 设置持久连接标志
        }
    }
    else if (strncasecmp(text, "Content-Length:", 15) == 0) {
        text += 15;
        text += strspn(text, " \t");
        m_content_length = atol(text);  // 记录内容长度
    }
    else if (strncasecmp(text, "Host:", 5) == 0) {
        text += 5;
        text += strspn(text, " \t");
        m_host = text;  // 记录主机名
    }
    else {
        printf("oop! unknow header %s\n", text);  // 忽略未知头部
    }
    
    return NO_REQUEST;
}
```

#### 2.3.4 内容体解析 - `parse_content()`
```cpp
HTTP_CODE http_conn::parse_content(char *text)
{
    // 检查是否已读取完整的内容体
    if (m_read_idx >= (m_content_length + m_checked_idx)) {
        text[m_content_length] = '\0';
        return GET_REQUEST;  // 内容体读取完成
    }
    return NO_REQUEST;  // 需要继续读取内容体
}
```

### 2.4 状态机转换流程图

```
初始状态: CHECK_STATE_REQUESTLINE
    ↓
解析请求行成功
    ↓
状态转移: CHECK_STATE_HEADER
    ↓
循环解析每个头部字段
    ↓
遇到空行(头部结束)
    ├── 如果有Content-Length > 0 → 转移到CHECK_STATE_CONTENT
    └── 否则 → 请求解析完成 → 调用do_request()
        ↓
CHECK_STATE_CONTENT状态下:
    ↓
读取指定长度的内容体
    ↓
内容体读取完成 → 调用do_request()
```

## 3. 请求处理阶段

### 3.1 文件请求处理 - `do_request()`
```cpp
HTTP_CODE http_conn::do_request()
{
    // 1. 构建完整文件路径: 根目录 + URL路径
    strcpy(m_real_file, doc_root);
    int len = strlen(doc_root);
    strncpy(m_real_file + len, m_url, FILENAME_LEN - len - 1);
    
    // 2. 获取文件状态信息
    if (stat(m_real_file, &m_file_stat) < 0) {
        return NO_RESOURCE;  // 文件不存在
    }
    
    // 3. 检查文件读取权限
    if (!(m_file_stat.st_mode & S_IROTH)) {
        return FORBIDDEN_REQUEST;  // 没有读取权限
    }
    
    // 4. 检查是否是目录
    if (S_ISDIR(m_file_stat.st_mode)) {
        return BAD_REQUEST;  // 不支持目录请求
    }
    
    // 5. 使用内存映射提高文件读取性能
    int fd = open(m_real_file, O_RDONLY);
    m_file_address = (char *)mmap(0, m_file_stat.st_size, 
                                  PROT_READ, MAP_PRIVATE, fd, 0);
    close(fd);
    
    return FILE_REQUEST;  // 文件请求处理成功
}
```

## 4. 响应生成阶段

### 4.1 响应生成状态机 - `process_write()`
```cpp
bool http_conn::process_write(HTTP_CODE ret)
{
    switch (ret) {
    case INTERNAL_ERROR:
        add_status_line(500, error_500_title);
        add_headers(strlen(error_500_form));
        add_content(error_500_form);
        break;
        
    case BAD_REQUEST:
        add_status_line(400, error_400_title);
        add_headers(strlen(error_400_form));
        add_content(error_400_form);
        break;
        
    case NO_RESOURCE:
        add_status_line(404, error_404_title);
        add_headers(strlen(error_404_form));
        add_content(error_404_form);
        break;
        
    case FORBIDDEN_REQUEST:
        add_status_line(403, error_403_title);
        add_headers(strlen(error_403_form));
        add_content(error_403_form);
        break;
        
    case FILE_REQUEST:  // 文件请求成功
        add_status_line(200, ok_200_title);
        if (m_file_stat.st_size != 0) {
            add_headers(m_file_stat.st_size);
            // 设置分散写参数：响应头 + 文件内容
            m_iv[0].iov_base = m_write_buf;
            m_iv[0].iov_len = m_write_idx;
            m_iv[1].iov_base = m_file_address;
            m_iv[1].iov_len = m_file_stat.st_size;
            m_iv_count = 2;
            return true;
        } else {
            // 空文件处理
            const char *ok_string = "<html><body></body></html>";
            add_headers(strlen(ok_string));
            add_content(ok_string);
        }
        break;
        
    default:
        return false;
    }
    
    // 错误响应只有响应头，没有文件内容
    m_iv[0].iov_base = m_write_buf;
    m_iv[0].iov_len = m_write_idx;
    m_iv_count = 1;
    return true;
}
```

### 4.2 响应发送 - `write()` 方法
```cpp
bool http_conn::write()
{
    int temp = 0;
    int bytes_have_send = 0;
    int bytes_to_send = m_write_idx;
    
    if (bytes_to_send == 0) {
        modfd(m_epollfd, m_sockfd, EPOLLIN);
        init();  // 重置连接状态
        return true;
    }

    while (1) {
        // 使用writev进行分散写（零拷贝技术）
        temp = writev(m_sockfd, m_iv, m_iv_count);
        
        if (temp <= -1) {
            if (errno == EAGAIN) {  // 写缓冲区满
                modfd(m_epollfd, m_sockfd, EPOLLOUT);
                return true;
            }
            unmap();  // 发送失败，释放资源
            return false;
        }

        bytes_to_send -= temp;
        bytes_have_send += temp;
        
        // 检查是否全部发送完成
        if (bytes_to_send <= bytes_have_send) {
            unmap();  // 发送完成，释放内存映射
            if (m_linger) {  // 持久连接
                init();  // 重置状态，准备处理下一个请求
                modfd(m_epollfd, m_sockfd, EPOLLIN);
                return true;
            } else {  // 非持久连接
                modfd(m_epollfd, m_sockfd, EPOLLIN);
                return false;  // 通知上层关闭连接
            }
        }
    }
}
```

## 6. 关键设计特点

### 6.1 有限状态机设计
- **三种解析状态**：请求行 → 头部 → 内容体
- **状态转移明确**：每个状态完成后自动转移到下一个状态
- **错误处理完善**：在任何状态发现错误立即终止解析

### 6.2 内存管理优化
- **固定大小缓冲区**：避免动态内存分配的开销
- **内存映射文件**：零拷贝文件传输，提高性能
- **分散写技术**：使用writev聚合多个缓冲区的写入操作

### 6.3 协议兼容性
- **严格遵循HTTP/1.1**：支持标准协议特性
- **持久连接支持**：正确处理Connection头部
- **错误处理完整**：生成标准的HTTP错误响应

### 6.4 性能优化
- **非阻塞I/O**：配合epoll边缘触发模式
- **零拷贝技术**：内存映射文件减少数据拷贝
- **缓冲区复用**：连接重置时重用缓冲区，减少分配开销

这个解析流程展示了高性能HTTP服务器如何高效处理请求，结合了状态机、零拷贝、非阻塞I/O等先进技术，能够处理大量并发连接。
