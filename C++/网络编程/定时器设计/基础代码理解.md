# 非活跃连接踢出机制示例程序详解

## 一、程序概述

这是一个基于**epoll + 定时器**的高性能网络服务器示例，实现了**非活跃连接自动踢出**功能。程序通过信号机制和定时器链表管理，能够自动检测并关闭长时间不活动的客户端连接。

## 二、核心机制

### 1. 技术架构
```
主线程 (epoll主循环)
    ├── 处理新连接 (accept)
    ├── 处理客户端数据收发
    ├── 处理定时信号 (通过管道)
    └── 定时器链表管理
```

### 2. 核心组件
- **epoll**: Linux高效I/O多路复用机制
- **定时器链表**: 维护所有连接的定时器
- **信号+管道**: 将异步信号转换为同步I/O事件
- **回调函数**: 定时器超时后的处理逻辑

## 三、程序详细流程

### 1. 初始化阶段
```c
// 1. 创建监听socket
listenfd = socket(PF_INET, SOCK_STREAM, 0);

// 2. 绑定和监听
bind(listenfd, (struct sockaddr *)&address, sizeof(address));
listen(listenfd, 5);

// 3. 创建epoll实例
epollfd = epoll_create(5);

// 4. 创建信号管道
socketpair(PF_UNIX, SOCK_STREAM, 0, pipefd);
// pipefd[0]: 读端，加入epoll监控
// pipefd[1]: 写端，信号处理函数写入
```

### 2. 信号处理机制
```c
// 信号处理流程
SIGALRM信号触发 → sig_handler() → 写入pipefd[1] → 
epoll监听到pipefd[0]可读 → 主循环读取并处理 → timer_handler()
```

**关键点**：
- 避免在信号处理函数中执行复杂操作
- 通过管道将信号转换为I/O事件
- 保持errno不被信号处理函数破坏

### 3. 定时器管理
```c
// 定时器结构
struct util_timer {
    time_t expire;              // 超时时间
    void (*cb_func)(client_data*); // 回调函数
    client_data* user_data;     // 用户数据
    util_timer* prev;           // 前驱节点
    util_timer* next;           // 后继节点
};

// 定时器链表操作
timer_lst.add_timer(timer);    // 添加定时器
timer_lst.del_timer(timer);    // 删除定时器
timer_lst.adjust_timer(timer); // 调整定时器
timer_lst.tick();              // 处理超时定时器
```

### 4. 主事件循环
```c
while (!stop_server) {
    // 1. 等待事件
    int number = epoll_wait(epollfd, events, MAX_EVENT_NUMBER, -1);
    
    for (int i = 0; i < number; i++) {
        int sockfd = events[i].data.fd;
        
        // 2. 处理不同类型的事件
        if (sockfd == listenfd) {
            // 新连接到达
        } 
        else if (sockfd == pipefd[0]) {
            // 信号到达
        } 
        else if (events[i].events & EPOLLIN) {
            // 客户端数据到达
        }
    }
    
    // 3. 处理定时事件
    if (timeout) {
        timer_handler();
        timeout = false;
    }
}
```

## 四、超时控制策略

### 1. 初始化超时时间
```c
// 新连接：超时时间 = 当前时间 + 3*TIMESLOT
time_t cur = time(NULL);
timer->expire = cur + 3 * TIMESLOT;  // 15秒后超时
```

### 2. 续期机制
```c
// 客户端有活动时，延长超时时间
if (timer) {
    time_t cur = time(NULL);
    timer->expire = cur + 3 * TIMESLOT;  // 重新设为15秒后
    timer_lst.adjust_timer(timer);      // 调整链表位置
}
```

### 3. 超时处理
```c
// 定时器回调函数
void cb_func(client_data *user_data) {
    epoll_ctl(epollfd, EPOLL_CTL_DEL, user_data->sockfd, 0);
    close(user_data->sockfd);
    printf("close fd %d\n", user_data->sockfd);
}
```

## 五、关键数据结构

### 1. 客户端数据
```c
struct client_data {
    sockaddr_in address;    // 客户端地址
    int sockfd;             // socket文件描述符
    char buf[BUFFER_SIZE];  // 接收缓冲区
    util_timer* timer;      // 关联的定时器
};
```

### 2. 定时器链表
- **升序双向链表**：按超时时间排序
- **快速定位**：O(1)时间添加/删除/调整定时器
- **惰性删除**：只在tick()时删除已超时定时器

## 六、信号处理细节

### 1. 信号注册
```c
void addsig(int sig) {
    struct sigaction sa;
    sa.sa_handler = sig_handler;     // 设置处理函数
    sa.sa_flags |= SA_RESTART;       // 被信号中断的系统调用自动重启
    sigfillset(&sa.sa_mask);         // 处理信号时阻塞所有信号
    sigaction(sig, &sa, NULL);
}
```

### 2. 信号写入管道
```c
void sig_handler(int sig) {
    int save_errno = errno;              // 保护errno
    int msg = sig;
    send(pipefd[1], (char *)&msg, 1, 0); // 写入信号编号
    errno = save_errno;                  // 恢复errno
}
```

## 七、性能优化考虑

### 1. 时间复杂度
- 添加定时器: O(n)，但通常n较小
- 删除定时器: O(1)
- 调整定时器: O(1)
- 处理超时: O(k)，k为超时定时器数量

### 2. 内存管理
- 使用预分配的`client_data`数组，以文件描述符为索引
- 避免频繁的内存分配和释放
- 定时器动态分配，在连接关闭时释放

## 八、程序特点

### 1. 优点
- **单一事件循环**：简化编程模型
- **非阻塞I/O**：充分利用epoll的边沿触发模式
- **统一信号处理**：避免信号处理函数的复杂性
- **精确超时控制**：支持动态调整超时时间

### 2. 适用场景
- 长连接服务（如游戏服务器、即时通讯）
- 需要管理大量空闲连接的场景
- 对资源占用敏感的服务
