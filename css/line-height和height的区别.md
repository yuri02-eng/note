# line-height 与 height 的区别

## 核心概念对比

| 特性 | line-height | height |
|------|------------|--------|
| **定义** | 行高，控制文本行之间的垂直间距 | 元素内容区域的高度 |
| **作用对象** | 主要针对文本内容 | 针对整个元素 |
| **继承性** | 可继承 | 不可继承 |
| **百分比值** | 相对于当前元素的字体大小 | 相对于父元素的高度 |
| **影响范围** | 影响行内元素和文本布局 | 影响块级元素的整体尺寸 |

## 详细解析

### line-height（行高）
- **功能**：控制文本行与行之间的垂直间距
- **取值类型**：
  - 数值：`1.5`（相对于当前字体大小的倍数）
  - 长度值：`20px`、`1.5em`
  - 百分比：`150%`（相对于当前字体大小）
- **默认值**：约为 `1.2`（取决于浏览器和字体）
- **特点**：
  - 会影响元素的实际高度（当元素包含文本时）
  - 可用于实现文本垂直居中

### height（高度）
- **功能**：设置元素内容区域的高度
- **取值类型**：
  - 固定值：`200px`
  - 百分比：`50%`（相对于父元素高度）
  - 自动：`auto`（由内容决定）
  - 视口单位：`50vh`（相对于视口高度）
- **默认值**：`auto`
- **特点**：
  - 确定元素的整体高度
  - 不会影响文本行间距

## 实际应用示例

### 示例1：单独使用 height
```css
.container {
  height: 100px;
  border: 1px solid #ccc;
}
```
- 元素总高度为100px
- 文本行高保持默认值，可能溢出或居上

### 示例2：单独使用 line-height
```css
.text {
  line-height: 1.5;
  border: 1px solid #ccc;
}
```
- 元素高度由文本行数 × line-height 决定
- 行间距舒适，适合阅读

### 示例3：结合使用实现垂直居中
```css
.box {
  height: 100px;
  line-height: 100px; /* 与height相同 */
}
```
- 单行文本在100px高的元素中垂直居中
- 多行文本不适合此方法

## 注意事项

1. **line-height 的继承**：
   ```css
   body {
     line-height: 1.6; /* 所有子元素继承此值 */
   }
   ```

2. **height 的溢出处理**：
   ```css
   .container {
     height: 100px;
     overflow: auto; /* 内容超出时显示滚动条 */
   }
   ```

3. **多行文本垂直居中**：
   - 使用 `display: table` + `vertical-align: middle`
   - 或使用 Flexbox/Grid 布局

## 总结

- **line-height** 主要用于控制文本布局和行间距
- **height** 用于控制元素的整体高度
- 两者可结合使用实现文本垂直居中效果
- 在实际开发中，需要根据内容类型和布局需求选择合适的属性
