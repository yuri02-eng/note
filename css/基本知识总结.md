# CSS 详细学习笔记

## 1. CSS 简介

CSS（Cascading Style Sheets）层叠样式表，用于描述HTML或XML文档的呈现方式，包括布局、颜色、字体等样式。

### 1.1 CSS 引入方式

```html
<!-- 1. 内联样式 -->
<div style="color: red;">内容</div>

<!-- 2. 内部样式表 -->
<head>
  <style>
    .content { color: blue; }
  </style>
</head>

<!-- 3. 外部样式表 -->
<head>
  <link rel="stylesheet" href="styles.css">
</head>
```

## 2. CSS 选择器

### 2.1 基础选择器

```css
/* 元素选择器 */
p { color: black; }

/* 类选择器 */
.class-name { color: blue; }

/* ID选择器 */
#id-name { color: red; }

/* 通配符选择器 */
* { margin: 0; padding: 0; }
```

### 2.2 组合选择器

```css
/* 后代选择器 */
div p { color: blue; }

/* 子选择器 */
div > p { color: red; }

/* 相邻兄弟选择器 */
div + p { color: green; }

/* 通用兄弟选择器 */
div ~ p { color: purple; }
```

### 2.3 属性选择器

```css
/* 存在属性选择器 */
[title] { color: blue; }

/* 精确属性值选择器 */
[type="text"] { background: yellow; }

/* 包含属性值选择器 */
[class~="box"] { border: 1px solid; }

/* 开头属性值选择器 */
[href^="https"] { color: green; }

/* 结尾属性值选择器 */
[src$=".jpg"] { border: 1px solid; }

/* 任意匹配属性值选择器 */
[class*="main"] { padding: 10px; }
```

### 2.4 伪类选择器

```css
/* 链接状态 */
a:link { color: blue; }
a:visited { color: purple; }
a:hover { color: red; }
a:active { color: orange; }

/* 元素状态 */
input:focus { background: yellow; }
input:disabled { opacity: 0.5; }
input:checked { accent-color: blue; }

/* 结构伪类 */
li:first-child { font-weight: bold; }
li:last-child { border-bottom: none; }
li:nth-child(odd) { background: #f0f0f0; }
li:nth-child(even) { background: #e0e0e0; }
li:nth-child(3n) { color: blue; }
```

### 2.5 伪元素选择器

```css
p::first-line { font-weight: bold; }
p::first-letter { font-size: 2em; }
p::selection { background: yellow; }
div::before { content: "前缀"; }
div::after { content: "后缀"; }
```

## 3. CSS 盒模型

### 3.1 标准盒模型

```css
.box {
  width: 300px;        /* 内容宽度 */
  height: 200px;       /* 内容高度 */
  padding: 20px;       /* 内边距 */
  border: 10px solid;  /* 边框 */
  margin: 30px;        /* 外边距 */
  /* 总宽度 = width + padding-left + padding-right + border-left + border-right */
}
```

### 3.2 替代(IE)盒模型

```css
.box {
  box-sizing: border-box;
  /* 总宽度 = width (包含padding和border) */
}
```

## 4. CSS 布局

### 4.1 浮动布局

```css
.container::after {
  content: "";
  display: table;
  clear: both;
}

.float-left {
  float: left;
  width: 50%;
}

.float-right {
  float: right;
  width: 50%;
}
```

### 4.2 定位

```css
.relative {
  position: relative;
  top: 10px;
  left: 20px;
}

.absolute {
  position: absolute;
  top: 0;
  right: 0;
}

.fixed {
  position: fixed;
  bottom: 0;
  left: 0;
}

.sticky {
  position: sticky;
  top: 0;
}
```

### 4.3 Flexbox 布局

```css
.container {
  display: flex;
  flex-direction: row; /* row, row-reverse, column, column-reverse */
  flex-wrap: wrap; /* nowrap, wrap, wrap-reverse */
  justify-content: flex-start; /* flex-start, flex-end, center, space-between, space-around, space-evenly */
  align-items: stretch; /* stretch, flex-start, flex-end, center, baseline */
  align-content: flex-start; /* 多行对齐方式 */
  gap: 10px; /* 项目间距 */
}

.item {
  flex: 1; /* flex-grow, flex-shrink, flex-basis */
  order: 1; /* 项目排序 */
  align-self: auto; /* 单个项目对齐方式 */
}
```

### 4.4 Grid 布局

```css
.container {
  display: grid;
  grid-template-columns: 100px 1fr 2fr;
  grid-template-rows: 50px 1fr 50px;
  grid-template-areas: 
    "header header header"
    "sidebar main main"
    "footer footer footer";
  gap: 10px;
  justify-items: stretch; /* 单元格水平对齐 */
  align-items: stretch;   /* 单元格垂直对齐 */
  justify-content: start; /* 网格水平对齐 */
  align-content: start;   /* 网格垂直对齐 */
}

.item {
  grid-column: 1 / 3;     /* 起始线 / 结束线 */
  grid-row: 1 / 2;        /* 起始线 / 结束线 */
  grid-area: header;      /* 区域名称 */
  justify-self: stretch;  /* 单个项目水平对齐 */
  align-self: stretch;    /* 单个项目垂直对齐 */
}
```

## 5. 常用CSS属性

### 5.1 文本属性

```css
.text {
  color: #333333;          /* 文字颜色 */
  font-family: Arial, sans-serif; /* 字体 */
  font-size: 16px;         /* 字体大小 */
  font-weight: normal;     /* 字体粗细 */
  font-style: italic;      /* 字体样式 */
  text-align: center;      /* 文本对齐 */
  line-height: 1.5;        /* 行高 */
  letter-spacing: 1px;     /* 字符间距 */
  word-spacing: 2px;       /* 单词间距 */
  text-decoration: underline; /* 文本修饰 */
  text-transform: uppercase; /* 文本转换 */
  text-indent: 2em;        /* 首行缩进 */
}
```

### 5.2 背景属性

```css
.element {
  background-color: #ffffff;      /* 背景颜色 */
  background-image: url("bg.jpg"); /* 背景图片 */
  background-repeat: no-repeat;    /* 重复方式 */
  background-position: center;     /* 位置 */
  background-size: cover;          /* 尺寸 */
  background-attachment: fixed;    /* 固定或滚动 */
  background: #fff url("bg.jpg") no-repeat center/cover fixed; /* 简写 */
}
```

### 5.3 边框与圆角

```css
.box {
  border: 1px solid #000;      /* 边框简写 */
  border-width: 1px;           /* 边框宽度 */
  border-style: solid;         /* 边框样式 */
  border-color: black;         /* 边框颜色 */
  border-radius: 10px;         /* 圆角 */
  border-top-left-radius: 5px; /* 单独圆角 */
  box-shadow: 2px 2px 5px rgba(0,0,0,0.3); /* 阴影 */
}
```

### 5.4 变换与动画

```css
.element {
  /* 变换 */
  transform: translate(50px, 100px); /* 移动 */
  transform: rotate(45deg);          /* 旋转 */
  transform: scale(1.5);             /* 缩放 */
  transform: skew(30deg, 20deg);     /* 倾斜 */
  transform-origin: center center;   /* 变换原点 */
  
  /* 过渡 */
  transition: all 0.3s ease-in-out;  /* 简写 */
  transition-property: width;        /* 过渡属性 */
  transition-duration: 0.3s;         /* 过渡时间 */
  transition-timing-function: ease;  /* 过渡函数 */
  transition-delay: 0.1s;            /* 过渡延迟 */
  
  /* 动画 */
  animation: slide 2s ease infinite; /* 简写 */
  animation-name: slide;             /* 动画名称 */
  animation-duration: 2s;            /* 动画时长 */
  animation-timing-function: ease;   /* 动画函数 */
  animation-delay: 0s;               /* 动画延迟 */
  animation-iteration-count: infinite; /* 迭代次数 */
  animation-direction: alternate;    /* 动画方向 */
  animation-fill-mode: forwards;     /* 填充模式 */
}

@keyframes slide {
  0% { transform: translateX(0); }
  100% { transform: translateX(100px); }
}
```

## 6. 响应式设计

### 6.1 媒体查询

```css
/* 设备宽度小于600px */
@media (max-width: 600px) {
  .container {
    flex-direction: column;
  }
}

/* 设备宽度在600px到900px之间 */
@media (min-width: 600px) and (max-width: 900px) {
  .sidebar {
    width: 50%;
  }
}

/* 设备方向 */
@media (orientation: landscape) {
  .header {
    height: 80px;
  }
}

/* 设备像素比 */
@media (-webkit-min-device-pixel-ratio: 2), (min-resolution: 192dpi) {
  .logo {
    background-image: url("logo@2x.png");
  }
}
```

### 6.2 响应式单位

```css
.container {
  width: 100%;          /* 百分比 */
  font-size: 1rem;     /* 根元素字体大小 */
  padding: 1em;        /* 当前元素字体大小 */
  height: 50vh;        /* 视口高度百分比 */
  width: 80vw;         /* 视口宽度百分比 */
  margin: 5vmin;       /* 视口较小尺寸的百分比 */
}
```

## 8. 现代CSS特性

```css

  display: grid;
  grid-template-columns: [start] 1fr [center] 1fr [end];
}

.item {
  grid-column: start / end;

  grid-template-columns: subgrid; /* 继承父网格 */
}
```

```css
  container-type: inline-size;

@container (min-width: 400px) {
  .card-content {
    display: flex;
  }
}
```

### 8.3 层叠层

```css
@layer base, components, utilities;

@layer base {
  h1 { font-size: 2rem; }
}

@layer components {
  .button { padding: 0.5rem 1rem; }
}

@layer utilities {
  .text-center { text-align: center; }
}
```

## 9. 性能与优化

```css
/* 使用will-change提示浏览器 */
.animated-element {
  will-change: transform, opacity;
}

/* 减少重绘区域 */
.container {
  contain: paint; /* 或 layout, size, content */
}

/* 使用content-visibility跳过渲染 */
.long-list {
  content-visibility: auto;
}

/* 使用backface-visibility优化3D变换 */
.card {
  backface-visibility: hidden;
}
```

## 10. CSS 方法论

```css

.menu { ... }

/* 元素 */
.menu__item { ... }

/* 修饰符 */
.menu__item--active { ... }
```

```css
/* 基础规则 */

/* 布局规则 */

.l-grid { ... }

/* 模块规则 */

.media { ... }

/* 状态规则 */

.is-active { ... }

```
