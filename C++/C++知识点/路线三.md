我直接帮你挑一批好用的 C++ 学习网站，你可以按阶段来用（全部都免费 / 有免费内容）。

## 一、零基础入门（中文）

1. **C++学习网**

   * 地址：studycpp
   * 特点：完全中文、从“什么是 C++、怎么装编译器、写第一个程序”开始，按章节学，很适合你这种基础还在打的人。([studycpp.cn][1])

2. **菜鸟教程 C++**

   * 地址：runoob C++ 教程([runoob.com][2])
   * 特点：每一小节都很短，配简单例子，适合“快速扫一遍语法＋查漏补缺”。

3. **C 语言中文网 C++ 教程**

   * 地址：c.biancheng.net/cplus/([c.biancheng.net][3])
   * 特点：内容比较系统，从基础语法、面向对象到 STL，都有成套文章，讲得比较细。

4. **W3Cschool C++ 教程**

   * 地址：w3cschool C++([w3cschool.cn][4])
   * 特点：结构和菜鸟类似，也可以当备选 / 对照着看。

---

## 二、进阶＋查手册（写代码时查资料）

1. **cppreference（英文，附带部分中文）**

   * 地址：en.cppreference.com([en.cppreference.com][5])
   * 用法：不是拿来“从头看”的，而是你写代码遇到：`std::vector`、`std::string`、`std::sort` 这种，就来查用法和例子。

2. **cpprefjp（日文 C++ 参考）**

   * 地址：cpprefjp.github.io([cpprefjp - C++日本語リファレンス][6])
   * 特点：如果你看得懂日文，这个对你在日本找工作/看日企代码非常有帮助，内容跟进最新标准。

---

## 三、系统学现代 C++（英文）

1. **LearnCpp.com**

   * 地址：learncpp.com([learncpp.com][7])
   * 特点：全球非常多人推荐，从基础一直讲到现代 C++（C++11 之后的新特性），适合你想“真的把 C++ 学扎实”。

2. **learn-cpp.org（在线交互教程）**

   * 地址：learn-cpp.org([learn-cpp.org][8])
   * 特点：网页里直接写代码运行，适合快速试语法、练习小题目。

3. **Learn Modern C++**

   * 地址：learnmoderncpp.com([Learn Modern C++][9])
   * 特点：专门围绕 “Modern C++”，偏进阶一点，适合你入门结束后往上走。

## 五、怎么用这些网站（给你一个简单顺序）

结合你之前问“Java 还是 C++ 就业”的情况，我按“从 0 到能做项目”的顺序给你一个推荐用法：

1. **第一阶段：语法入门（1–2 周）**

   * 任选一个中文教程主攻：

     * 推荐：**C++学习网** 或 **C 语言中文网 C++**
   * 目标：

     * 会写：变量、if/for/while、数组、函数、结构体、类与对象、简单输入输出。

2. **第二阶段：面向对象＋STL（2–4 周）**

   * 继续看你选的主站后半部分，补：

     * 类/继承/多态、`std::string`、`std::vector`、`std::map` 等。
   * 遇到标准库细节不懂：去 **cppreference / cpprefjp** 查。

3. **第三阶段：现代 C++ 和项目实战**

   * 用 **LearnCpp.com** 按章节刷一遍（重点看 C++11 以后的内容）。
   * 同时做点小项目：简单通讯录、学生管理系统、小游戏、OJ 刷题等。
