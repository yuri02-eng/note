### **C++中的纯虚函数、抽象基类和接口类**

#### **1. 纯虚函数的概念**

C++允许你创建**纯虚函数**，这种特殊的虚函数没有函数体，它仅充当占位符，指示派生类需要重写该函数。纯虚函数的声明中，使用 `= 0` 来标识函数为纯虚。

##### **创建纯虚函数**

为了创建纯虚函数，我们只需要在函数声明末尾加上 `= 0`：

```cpp
virtual int getValue() const = 0;  // 纯虚函数声明
```

### **2. 纯虚函数的作用**

* **标记抽象基类**：任何包含一个或多个纯虚函数的类都被认为是**抽象基类**（abstract base class）。这种类不能被实例化，意味着不能创建该类的对象。
* **派生类要求实现**：派生类必须为所有纯虚函数提供实现，否则它也将成为抽象基类。

### **3. 抽象基类**

当类包含纯虚函数时，这个类被称为抽象基类。抽象基类不能实例化，不能直接创建它的对象，但可以作为派生类的基类使用。

```cpp
class Base {
    virtual void function1() = 0; // 纯虚函数
};
```

在这个例子中，`Base` 是一个抽象基类，因为它有一个纯虚函数 `function1()`。不能创建 `Base` 类的对象，必须通过派生类来实现这个函数。

### **4. 纯虚函数的示例**

```cpp
#include <iostream>
#include <string_view>

class Animal {
protected:
    std::string m_name;

public:
    Animal(std::string_view name) : m_name(name) {}

    const std::string& getName() const { return m_name; }

    virtual std::string_view speak() const = 0;  // 纯虚函数

    virtual ~Animal() = default;  // 虚析构函数
};

class Cat : public Animal {
public:
    Cat(std::string_view name) : Animal(name) {}

    std::string_view speak() const override { return "Meow"; }
};

class Dog : public Animal {
public:
    Dog(std::string_view name) : Animal(name) {}

    std::string_view speak() const override { return "Woof"; }
};

int main() {
    Cat cat{"Whiskers"};
    Dog dog{"Buddy"};

    std::cout << cat.getName() << " says " << cat.speak() << '\n';
    std::cout << dog.getName() << " says " << dog.speak() << '\n';

    return 0;
}
```

在这个例子中，`Animal` 类是一个抽象基类，定义了一个纯虚函数 `speak()`。`Cat` 和 `Dog` 类从 `Animal` 派生，并分别实现了 `speak()` 函数。因此，我们可以实例化 `Cat` 和 `Dog` 类的对象。

### **5. 纯虚函数和基类指针的使用**

```cpp
Animal* animal1 = new Cat("Whiskers");
Animal* animal2 = new Dog("Buddy");

std::cout << animal1->getName() << " says " << animal1->speak() << '\n';
std::cout << animal2->getName() << " says " << animal2->speak() << '\n';
```

* 在这里，`animal1` 和 `animal2` 是指向基类 `Animal` 的指针，实际上它们指向的是派生类 `Cat` 和 `Dog` 的对象。通过基类指针调用虚函数 `speak()` 时，C++ 会根据实际对象的类型调用相应的派生类实现（即 `Cat::speak()` 或 `Dog::speak()`）。这就是 **多态性** 的表现。

### **6. 纯虚函数的未实现情况**

如果你忘记在派生类中实现纯虚函数，编译器会报错，因为派生类仍然是抽象基类，不能实例化。例如：

```cpp
class Cow : public Animal {
public:
    Cow(std::string_view name) : Animal(name) {}

    // 忘记实现 speak()
};

int main() {
    Cow cow("Betsy");  // 编译错误：无法实例化抽象类
    return 0;
}
```

编译器会给出错误提示，告知 `Cow` 类缺少纯虚函数 `speak()` 的实现。

### **7. 具有定义的纯虚函数**

有时我们希望为纯虚函数提供一个默认的实现。为了给纯虚函数提供定义，定义必须在类外部给出，而不是在类内部。

```cpp
class Animal {
public:
    virtual std::string_view speak() const = 0;  // 纯虚函数

    virtual ~Animal() = default;
};

// 定义纯虚函数
std::string_view Animal::speak() const {
    return "Some generic sound";
}

class Dog : public Animal {
public:
    std::string_view speak() const override {
        return "Woof";
    }
};

int main() {
    Dog dog{"Buddy"};
    std::cout << dog.getName() << " says " << dog.speak() << '\n';
}
```

* 在这种情况下，`speak()` 函数仍然是纯虚函数，但我们为其提供了一个默认的实现。派生类 `Dog` 覆盖了这个函数，调用时返回 `Woof`。
* 如果派生类没有提供 `speak()` 的实现，则会使用基类的默认实现。

### **8. 接口类**

接口类是没有成员变量的类，其中所有函数都是纯虚函数。接口类用于定义一组功能规范，具体的实现由派生类提供。C++没有专门的 `interface` 关键字，但可以通过纯虚函数实现接口类的功能。

#### **接口类的示例**

```cpp
class IErrorLog {
public:
    virtual bool openLog(std::string_view filename) = 0;
    virtual bool closeLog() = 0;
    virtual bool writeError(std::string_view errorMessage) = 0;

    virtual ~IErrorLog() {}  // 有虚函数的类，析构函数也必须是虚函数
};
```

* **`IErrorLog` 接口类**：定义了三个纯虚函数，派生类必须实现这些函数，才能实例化对象。

#### **接口类的实现**

```cpp
class FileErrorLog : public IErrorLog {
public:
    bool openLog(std::string_view filename) override {
        // 打开日志文件
        return true;
    }

    bool closeLog() override {
        // 关闭日志文件
        return true;
    }

    bool writeError(std::string_view errorMessage) override {
        // 将错误写入文件
        return true;
    }
};

class ScreenErrorLog : public IErrorLog {
public:
    bool openLog(std::string_view filename) override {
        // 不做任何事
        return true;
    }

    bool closeLog() override {
        // 不做任何事
        return true;
    }

    bool writeError(std::string_view errorMessage) override {
        std::cout << "Error: " << errorMessage << std::endl;
        return true;
    }
};
```

* **`FileErrorLog` 和 `ScreenErrorLog`**：这两个类分别实现了 `IErrorLog` 接口，`FileErrorLog` 将错误写入文件，而 `ScreenErrorLog` 将错误打印到屏幕。

#### **接口类的使用**

```cpp
void logError(IErrorLog& log) {
    log.writeError("An error occurred");
}

int main() {
    FileErrorLog fileLog;
    ScreenErrorLog screenLog;

    logError(fileLog);   // 使用 FileErrorLog
    logError(screenLog); // 使用 ScreenErrorLog

    return 0;
}
```

* **`logError` 函数**：这个函数接受任何实现了 `IErrorLog` 接口的对象作为参数，可以是 `FileErrorLog` 也可以是 `ScreenErrorLog`。这样，我们可以灵活地选择不同的日志实现，而不需要修改 `logError` 函数的代码。

### **9. 纯虚函数和虚函数表**

纯虚函数的类（抽象基类）也有虚函数表。对于纯虚函数，虚函数表条目通常会包含空指针，或者指向一个错误处理函数（例如 `__purecall`）。如果纯虚函数的类没有提供默认实现，那么调用这些纯虚函数时将会遇到错误。

### **10. 总结**

* **纯虚函数**：它没有函数体，派生类必须实现它，否则派生类也会变成抽象基类。
* **抽象基类**：包含纯虚函数的类称为抽象基类，不能被实例化。
* **接口类**：没有成员变量，所有成员函数都是纯虚函数的类。用于定义一组行为，派生类提供具体实现。
* **虚函数表**：即使是抽象类，它仍然有虚函数表，用于支持动态绑定。

通过这些特性，C++ 提供了灵活的多态性机制，使得程序更具扩展性和可维护性。
