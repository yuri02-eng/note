# CSS 水平垂直居中完全指南

## 核心方法分类

| 方法类型 | 适用场景 | 兼容性 | 特点 |
|---------|---------|-------|------|
| Flexbox | 现代布局首选 | IE10+ | 简洁灵活，响应式友好 |
| Grid | 二维布局 | IE不支持 | 强大但兼容性较差 |
| 定位法 | 传统方案 | 全兼容 | 需要知道尺寸或使用transform |
| 表格法 | 传统方案 | 全兼容 | 语义化较差 |
| 行高法 | 单行文本 | 全兼容 | 仅限单行文本内容 |
| margin法 | 块级元素 | 全兼容 | 需要知道元素尺寸 |

## 一、Flexbox 方案（推荐）

### 1. 父容器控制
```css
.container {
  display: flex;
  justify-content: center; /* 水平居中 */
  align-items: center;     /* 垂直居中 */
}
```

### 2. 子元素自身控制
```css
.center-element {
  margin: auto; /* Flex容器中子元素可用 */
}
```

### 3. 多个元素居中
```css
.container {
  display: flex;
  justify-content: center;
  align-items: center;
  flex-direction: column; /* 垂直排列时 */
}
```

## 二、Grid 方案

### 1. 单元素居中
```css
.container {
  display: grid;
  place-items: center; /* 简写属性 */
}
```

### 2. 显式指定
```css
.container {
  display: grid;
  justify-content: center; /* 水平 */
  align-content: center;   /* 垂直 */
}
```

## 三、定位法（Positioning）

### 1. 已知元素尺寸
```css
.container {
  position: relative;
}

.center-element {
  position: absolute;
  top: 50%;
  left: 50%;
  margin-top: -50px;  /* 高度的一半 */
  margin-left: -100px; /* 宽度的一半 */
  width: 200px;
  height: 100px;
}
```

### 2. 未知元素尺寸（推荐）
```css
.container {
  position: relative;
}

.center-element {
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
}
```

### 3. 全屏居中
```css
.center-element {
  position: fixed;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
}
```

## 四、表格法（Table）

### 1. 传统表格布局
```css
.container {
  display: table;
  width: 100%;
  height: 100%;
}

.center-wrapper {
  display: table-cell;
  text-align: center; /* 水平居中 */
  vertical-align: middle; /* 垂直居中 */
}

.center-element {
  display: inline-block; /* 或 inline */
}
```

### 2. 现代替代方案
```css
.container {
  display: grid;
  place-items: center;
}
```

## 五、文本居中法

### 1. 单行文本居中
```css
.container {
  text-align: center; /* 水平居中 */
  line-height: 300px; /* 等于容器高度 */
}
```

### 2. 多行文本居中
```css
.container {
  display: flex;
  justify-content: center;
  align-items: center;
  text-align: center;
}
```

## 六、Margin 居中法

### 1. 水平居中（块级元素）
```css
.center-element {
  width: 300px;
  margin: 0 auto; /* 水平居中 */
}
```

### 2. 垂直居中（需要容器高度）
```css
.container {
  height: 500px;
}

.center-element {
  height: 100px;
  margin: 200px auto 0; /* (500-100)/2 = 200 */
}
```

## 七、响应式居中技巧

### 1. 视口单位居中
```css
.center-element {
  position: absolute;
  top: 50vh; /* 视口高度的50% */
  left: 50vw; /* 视口宽度的50% */
  transform: translate(-50%, -50%);
}
```

### 2. Flexbox + 自动边距
```css
.container {
  display: flex;
  min-height: 100vh; /* 确保容器高度 */
}

.center-element {
  margin: auto; /* 自动计算边距 */
}
```

## 八、特殊场景解决方案

### 1. 图片居中
```css
.container {
  display: flex;
  justify-content: center;
  align-items: center;
}

.container img {
  max-width: 100%;
  max-height: 100%;
}
```

### 2. 浮动元素居中
```css
/* 不推荐使用浮动进行居中 */
/* 替代方案：使用Flexbox或Grid */
```

### 3. 绝对定位元素在滚动容器中居中
```css
.container {
  position: relative;
  overflow: auto;
}

.center-element {
  position: absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
}
```

## 最佳实践建议

1. **现代布局首选 Flexbox** - 简洁高效，兼容性好
2. **未知尺寸元素使用 transform 定位法** - 最灵活的传统方案
3. **避免使用负 margin 定位** - 难以维护，不灵活
4. **考虑使用 CSS 变量** - 方便调整和维护
   ```css
   :root {
     --center-x: 50%;
     --center-y: 50%;
   }
   
   .center-element {
     position: absolute;
     top: var(--center-y);
     left: var(--center-x);
     transform: translate(-50%, -50%);
   }
   ```

5. **测试不同设备和浏览器** - 特别是需要支持旧版浏览器时

## 浏览器兼容性参考

| 方法 | Chrome | Firefox | Safari | Edge | IE |
|------|--------|---------|--------|------|----|
| Flexbox | 29+ (21+前缀) | 28+ (18+前缀) | 9+ (6.1+前缀) | 12+ | 11+ (10+前缀) |
| Grid | 57+ | 52+ | 10.1+ | 16+ | ✘ |
| Transform | 36+ (4+前缀) | 16+ (3.5+前缀) | 9+ (3.1+前缀) | 12+ | 10+ (9+前缀) |
| Table | 全支持 | 全支持 | 全支持 | 全支持 | 全支持 |

## 总结

选择居中方法时应考虑：
1. 需要居中的元素类型（文本、图片、块级元素）
2. 元素尺寸是否已知
3. 浏览器兼容性要求
4. 布局上下文（流式布局、固定布局等）

**推荐优先级：**
1. Flexbox（现代布局首选）
2. transform + 定位（兼容性好）
3. Grid（二维布局需求）
4. 表格法（传统方案备选）

通过掌握这些方法，你可以应对任何水平垂直居中的需求场景。
