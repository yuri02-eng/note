### **函数式编程进阶：函数组合与记忆化**

#### **一、 函数组合**

**1. 核心思想**
函数组合是将多个简单函数**组合**成一个更复杂的新函数的过程。数据像流水一样，从一个函数的输出流向下一个函数的输入，直到得到最终结果。

*   **数学基础**：在数学中，函数组合表示为： `(f ∘ g)(x) = f(g(x))`。即，先执行 `g(x)`，将其结果作为参数传递给 `f`。
*   **编程理念**：**通过组合简单、单一职责的小函数来构建复杂功能**，而不是编写一个庞大、功能繁杂的大函数。

**2. 为何重要？**
*   **提升可读性**：代码声明性更强，清晰地展示了“数据经过了怎样的处理流程”，如 `validate(clean(format(input)))`。
*   **增强可维护性**：每个小函数易于测试、理解和复用。修改其中一个不会影响其他部分。
*   **促进解耦**：函数之间没有紧耦合，只通过输入和输出连接。

**3. 如何实现？**
在支持一等函数的语言中（如 JavaScript），我们可以轻松实现一个组合函数。

```javascript
// 一个简单的组合函数实现
// compose(f, g, h) 返回一个新函数，执行时相当于 f(g(h(...args)))
const compose = (...fns) => (initialValue) =>
  fns.reduceRight((value, fn) => fn(value), initialValue);
//接受多参数的组合函数
function compose(...fns) {
  return fns.reduce((f, g) => (...args) => f(g(...args)));
}
// 或者，一个从右向左的组合（更符合数学写法）
// pipe（管道）函数，从左向右执行，更符合直觉
const pipe = (...fns) => (initialValue) =>
  fns.reduce((value, fn) => fn(value), initialValue);
```

**4. 代码示例**
假设我们有一个用户对象，需要经过一系列处理：

```javascript
// 1. 定义一系列单一职责的纯函数
const getUser = (id) => ({ id, name: 'Alice', age: 30, salary: 50000 }); // 模拟获取用户
const getAnnualSalary = (user) => user.salary * 12;
const deductTax = (salary) => salary * 0.8; // 扣除20%税
const formatCurrency = (amount) => `$${amount.toFixed(2)}`;

// 2. 使用组合（从右向左：先执行getAnnualSalary，然后deductTax，最后formatCurrency）
const getNetIncome = compose(formatCurrency, deductTax, getAnnualSalary);

// 3. 使用管道（从左向右：先getUser，然后getAnnualSalary，然后deductTax，最后formatCurrency）
const getNetIncomePipe = pipe(getUser, getAnnualSalary, deductTax, formatCurrency);

// 4. 使用
const userId = 123;
const netIncome = getNetIncome(getUser(userId));
console.log(netIncome); // 输出: "$480000.00"

const netIncome2 = getNetIncomePipe(userId);
console.log(netIncome2); // 输出: "$480000.00"
```

#### **二、 记忆化**

**1. 核心思想**
记忆化是一种**优化技术**，通过缓存特定输入对应的函数计算结果。当再次以相同的输入调用该函数时，直接返回缓存的结果，而无需重新计算。

*   **前提条件**：该函数必须是**纯函数**。因为纯函数的输出只由输入决定，所以相同的输入总是可以安全地返回相同的缓存输出。

**2. 为何重要？**
*   **性能提升**：避免对昂贵计算（如复杂数学运算、递归）的重复执行，显著加快程序速度。
*   **成本节省**：避免重复的API调用或数据库查询（但需注意缓存失效策略）。

**3. 如何实现？**
通常使用**闭包**和一个**缓存对象**（如 Map 或普通对象）来实现。

```javascript
// 一个简单的记忆化函数实现
function memoize(fn) {
  const cache = new Map(); // 使用Map作为缓存池

  return function (...args) {
    // 创建一个唯一的键来标识这组参数
    // 注意：这里简化了，对于复杂对象参数，需要更复杂的序列化方法
    const key = JSON.stringify(args);

    if (cache.has(key)) {
      console.log('Fetching from cache:', key);
      return cache.get(key);
    }

    console.log('Calculating result...');
    const result = fn.apply(this, args);
    cache.set(key, result);
    return result;
  };
}
```

**4. 代码示例**
以经典的斐波那契数列计算为例，其递归实现效率极低，非常适合用记忆化优化。

```javascript
// 未记忆化的斐波那契函数（效率极低）
function fibonacci(n) {
  if (n < 2) return n;
  return fibonacci(n - 1) + fibonacci(n - 2);
}

// 记忆化版本
const memoizedFibonacci = memoize(function (n) {
  if (n < 2) return n;
  // 关键：这里递归调用的是 memoizedFibonacci，而不是原始的 fibonacci
  return memoizedFibonacci(n - 1) + memoizedFibonacci(n - 2);
});

// 测试
console.time('First call');
console.log(memoizedFibonacci(40)); // 计算并缓存所有中间结果
console.timeEnd('First call');       // 耗时较长

console.time('Second call');
console.log(memoizedFibonacci(40)); // 直接从缓存中获取结果
console.timeEnd('Second call');      // 耗时极短

console.log(memoizedFibonacci(10)); // 由于计算f(40)时已经计算过f(10)，所以也直接从缓存获取
```

**5. 注意事项**
*   **内存消耗**：缓存会占用内存。需要在**CPU时间**和**内存空间**之间做出权衡。
*   **缓存失效**：对于需要缓存时效的场景（如API数据变化），需要设计复杂的缓存失效策略。
*   **参数序列化**：简单的 `JSON.stringify` 可能无法处理所有参数类型（如函数、循环引用的对象）。

#### **三、 组合与记忆化的关系**

虽然它们是独立的概念，但可以协同工作，构建出既清晰又高效的程序。

*   **组合**负责**构建程序逻辑**，将复杂任务分解为纯函数的流水线。
*   **记忆化**负责**优化性能**，对那些计算成本高、被频繁调用的纯函数进行缓存。

**典型工作流**：
1.  使用**函数组合**将业务逻辑拆解为一连串小的纯函数，并组合起来。这使得代码清晰、模块化。
2.  识别出组合链条中**计算昂贵**的纯函数。
3.  使用**记忆化**对这些昂贵函数进行包装和优化。
4.  现在，你得到了一个既易于理解和维护，又拥有高性能的程序。

```javascript
// 组合多个函数
const processData = pipe(fetchData, expensiveTransformation, formatOutput);

// 优化其中的昂贵步骤
const memoizedExpensiveTransformation = memoize(expensiveTransformation);
const optimizedProcessData = pipe(fetchData, memoizedExpensiveTransformation, formatOutput);
```

#### **总结对比表**

| 特性 | 函数组合 | 记忆化 |
| :--- | :--- | :--- |
| **目的** | 代码架构、逻辑组织、提升可读性与可维护性 | 性能优化、避免重复计算 |
| **核心** | 将函数串联成管道 | 缓存输入输出结果 |
| **前提** | 函数最好为纯函数（输出可预测） | **函数必须为纯函数**（缓存才有效） |
| **结果** | 产生一个新的函数 | 产生一个带缓存的新函数 |
| **关注点** | 可维护性、声明式编程 | 执行效率、时间复杂度 |

## 一、函数组合技术

### 1.1 核心概念
函数组合是将多个简单函数组合成一个新函数的过程，数据像流水线一样从一个函数的输出流向下一个函数的输入。

**数学表示**：`(f ∘ g)(x) = f(g(x))`

### 1.2 基础实现

#### 从右向左组合（标准compose）
```javascript
// reduce实现
// 实现方式：reduce（高阶函数方式）
function compose(...fns) {
  return fns.reduce((f, g) => (...args) => f(g(...args)));
}
// reduceRight实现
const compose = (...fns) => {
  return (...args) => {
    return fns.reduceRight((result, fn) => {
      return Array.isArray(result) ? fn(...result) : fn(result);
    }, args);
  };
};
```

#### 从左向右组合（pipe管道）
```javascript
const pipe = (...fns) => {
  return (...args) => {
    return fns.reduce((result, fn) => {
      return Array.isArray(result) ? fn(...result) : fn(result);
    }, args);
  };
};
// 实现方式：reduce（高阶函数方式）
function compose(...fns) {
  return fns.reduce((f, g) => (...args) => g(f(...args)));
}
```

### 1.3 高级组合技巧

```javascript
const curry = (fn) => {

    return (...moreArgs) => curried(...args, ...moreArgs);
  };
};

// 使用示例

const multiply = curry((a, b) => a * b);
```


## 二、记忆化技术

### 2.1 核心概念
记忆化是一种优化技术，通过缓存函数计算结果来避免重复计算，前提是函数必须是纯函数。

### 2.2 基础实现
```javascript
const memoize = (fn) => {
  const cache = new Map();
  
  return (...args) => {
    const key = JSON.stringify(args);
    
    if (cache.has(key)) {
      return cache.get(key);
    }
    
    const result = fn(...args);
    cache.set(key, result);
    return result;
  };
};
```

### 2.3 高级实现

#### 带缓存控制的记忆化
```javascript
const advancedMemoize = (fn, options = {}) => {
  const {
    maxSize = 100,
    maxAge = null, // 毫秒
    resolver = (...args) => JSON.stringify(args)
  } = options;
  
  const cache = new Map();
  const timestamps = new Map();
  
  return function(...args) {
    const key = resolver(...args);
    const now = Date.now();
    
    // 检查缓存是否存在且未过期
    if (cache.has(key)) {
      if (!maxAge || (now - timestamps.get(key)) < maxAge) {
        return cache.get(key);
      }
      // 缓存过期，清除
      cache.delete(key);
      timestamps.delete(key);
    }
    
    // 执行缓存淘汰策略
    if (cache.size >= maxSize) {
      const oldestKey = [...timestamps.entries()]
        .reduce((oldest, [key, time]) => 
          time < timestamps.get(oldest) ? key : oldest, 
          timestamps.keys().next().value
        );
      cache.delete(oldestKey);
      timestamps.delete(oldestKey);
    }
    
    // 计算并缓存结果
    const result = fn.apply(this, args);
    cache.set(key, result);
    timestamps.set(key, now);
    
    return result;
  };
};
```

#### 基于WeakMap的对象键记忆化
```javascript
const weakMemoize = fn => {
  const cache = new WeakMap();
  
  return obj => {
    if (!cache.has(obj)) {
      cache.set(obj, fn(obj));
    }
    return cache.get(obj);
  };
};
```

### 2.4 记忆化策略

#### LRU（最近最少使用）缓存
```javascript
class LRUCache {
  constructor(maxSize = 100) {
    this.maxSize = maxSize;
    this.cache = new Map();
  }
  
  get(key) {
    if (!this.cache.has(key)) return undefined;
    
    const value = this.cache.get(key);
    this.cache.delete(key);
    this.cache.set(key, value);
    return value;
  }
  
  set(key, value) {
    if (this.cache.has(key)) {
      this.cache.delete(key);
    } else if (this.cache.size >= this.maxSize) {
      this.cache.delete(this.cache.keys().next().value);
    }
    this.cache.set(key, value);
  }
}

const memoizeWithLRU = (fn, maxSize = 100) => {
  const cache = new LRUCache(maxSize);
  const resolver = (...args) => JSON.stringify(args);
  
  return function(...args) {
    const key = resolver(...args);
    if (cache.get(key) !== undefined) {
      return cache.get(key);
    }
    
    const result = fn(...args);
    cache.set(key, result);
    return result;
  };
};
```

#### 异步函数记忆化
```javascript
const memoizeAsync = (fn, options = {}) => {
  const cache = new Map();
  const pending = new Map();
  
  return async function(...args) {
    const key = JSON.stringify(args);
    
    if (cache.has(key)) {
      return cache.get(key);
    }
    
    if (pending.has(key)) {
      return pending.get(key);
    }
    
    const promise = fn(...args).then(result => {
      cache.set(key, result);
      pending.delete(key);
      return result;
    }).catch(error => {
      pending.delete(key);
      throw error;
    });
    
    pending.set(key, promise);
    return promise;
  };
};
```

## 五、最佳实践与注意事项

### 5.1 函数组合最佳实践
1. **保持函数纯净**：确保组合中的函数都是纯函数
2. **单一职责原则**：每个函数应该只做一件事
3. **合理命名**：使用描述性名称提高代码可读性
4. **渐进式组合**：从简单组合开始，逐步构建复杂功能
5. **注意参数传递**：确保函数参数兼容性

### 5.2 记忆化最佳实践
1. **仅记忆化纯函数**：确保函数输出完全由输入决定
2. **合理设置缓存大小**：根据内存限制调整缓存策略
3. **考虑缓存失效**：对于动态数据设计合适的缓存失效机制
4. **性能测试**：使用性能分析工具确定需要记忆化的函数
5. **内存监控**：在内存敏感环境中监控缓存使用情况

### 5.3 注意事项
- 记忆化会增加内存消耗，需在CPU时间和内存空间之间权衡
- 复杂对象作为参数时需要特殊序列化处理
- 避免记忆化那些参数组合极多但重复调用少的函数
- 在并发环境中需要注意缓存的一致性问题
