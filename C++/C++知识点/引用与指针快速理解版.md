## **C++ 中的 引用 (`&`) 和 指针 (`*`)**

### **1. 引用（`&`）**

引用是 C++ 中的一种数据类型，它为现有变量提供了一个 **别名**，也就是说，引用与它所引用的变量共享相同的内存位置。引用在定义时必须初始化，并且一旦绑定到一个变量，就不能改变绑定的对象。

#### **声明引用**

```cpp
int a = 10;
int& ref = a;  // ref 是 a 的别名
```

* 在这里，`ref` 是 `a` 的引用，它就像 `a` 的别名。你可以通过 `ref` 来访问和修改 `a`。
* **`ref` 和 `a` 是同一个变量**，修改 `ref` 就是修改 `a`。

#### **引用的赋值**

```cpp
int b = 20;
ref = b;  // 将 b 的值赋给 ref
```

* **`ref = b` 并不意味着 `ref` 绑定到 `b`**。实际上，`ref` 仍然是 `a` 的引用，`ref = b` 只是将 `b` 的值赋给了 `a`。此时，`a` 的值变为 `b` 的值，即 20。

### **2. 指针（`*`）**

指针是存储另一个变量的内存地址的变量。通过指针，我们可以间接访问变量的值，也可以通过指针修改变量。

#### **声明指针**

```cpp
int a = 10;
int* ptr = &a;  // ptr 存储 a 的地址
```

* 这里，`ptr` 是指向 `a` 的指针，它存储了 `a` 的内存地址。`&a` 表示取 `a` 的地址。

#### **通过指针修改值**

```cpp
*ptr = 30;  // 通过 ptr 修改 a 的值
```

* **`*ptr`** 是对 `ptr` 指向对象的解引用，它访问并修改 `ptr` 所指向的内存位置，即修改 `a` 的值。因此，`a` 的值被修改为 30。

### **3. `*ptr` 返回的是引用吗？**

`*ptr` 在 C++ 中是 **解引用操作符**，它返回指针 `ptr` 所指向对象的 **引用**。也就是说，`*ptr` 是一个 **左值引用**，你可以通过它来直接访问指针所指向的对象。

#### **示例：**

```cpp
int a = 10;
int* ptr = &a;
int& reff = *ptr;  // reff 是 *ptr 的引用，它引用了 a
```

* **`*ptr`** 返回的是 `ptr` 指向的对象（在这里是 `a`）的引用。
* `reff` 是 `*ptr` 的引用，因此，`reff` 也是 `a` 的引用。修改 `reff` 相当于修改 `a`。

### **4. `int& reff = *ptr;` 与 `int reff = *ptr;` 的区别**

* **`int& reff = *ptr;`**：这里 `reff` 是一个 **引用**，它引用了 `*ptr`。`reff` 和 `*ptr` 是同一个对象，修改 `reff` 会直接影响 `a`，因为 `reff` 实际上是 `a` 的引用。

* **`int reff = *ptr;`**：这里 `reff` 是一个 **普通变量**，它存储 `*ptr` 的值（即 `a` 的值）。这只是 **值的拷贝**，修改 `reff` 并不会影响 `a`。

### **5. 完整示例：**

```cpp
#include <iostream>

int main() {
    int a = 10;
    int b = 20;

    // 引用：ref 是 a 的别名
    int& ref = a;  
    ref = b;  // ref 指向 a，改变 ref 相当于改变 a 的值，所以 a 变成了 20
    std::cout << "a: " << a << std::endl;  // 输出 20

    // 指针：ptr 存储 a 的地址
    int* ptr = &a;  
    *ptr = 30;  // 通过 ptr 修改 a 的值，所以 a 变成了 30
    std::cout << "a: " << a << std::endl;  // 输出 30

    // 将 *ptr 保留下来作为引用
    int& reff = *ptr;  // reff 是 *ptr 的引用
    reff = 40;  // 修改 reff，也就是修改 a 的值
    std::cout << "a: " << a << std::endl;  // 输出 40

    // 使用 int reff = *ptr; 赋值（复制）副本
    int reff_copy = *ptr;  // reff_copy 是 a 的副本
    reff_copy = 50;  // 修改 reff_copy，不会影响 a
    std::cout << "a: " << a << std::endl;  // 输出 40
    std::cout << "reff_copy: " << reff_copy << std::endl;  // 输出 50

    return 0;
}
```

### **6. 总结**

| 代码                  | 含义                                                        |
| ------------------- | --------------------------------------------------------- |
| `int& ref = a;`     | **`ref` 是 `a` 的引用**，任何对 `ref` 的修改都会影响 `a`。                |
| `int* ptr = &a;`    | **`ptr` 是 `a` 的指针**，它存储了 `a` 的内存地址。通过 `*ptr` 可以修改 `a` 的值。 |
| `int& reff = *ptr;` | **`reff` 是 `*ptr` 的引用**，即 `a` 的引用，修改 `reff` 直接修改 `a`。     |
| `int reff = *ptr;`  | **`reff` 是 `a` 的副本**，修改 `reff` 不会影响 `a`。                  |

* **引用** (`int&`) 和 **指针** (`int*`) 都用于访问和修改对象，但引用本质上是对象的别名，而指针是存储地址的变量。
* 通过指针访问对象需要使用解引用操作符 (`*`)。
* **引用**（`int& reff = *ptr;`）让你直接修改对象，而 **值**（`int reff = *ptr;`）只是存储对象的副本，修改副本不会影响原对象。
