### **C++ 虚函数表（vtable）及其工作原理**

#### **1. 虚函数表的基本概念**

在 C++ 中，当一个类包含虚函数时，编译器会为该类创建一个虚函数表（**vtable**）。虚函数表是一个静态数组，包含了类的虚函数指针。每个包含虚函数的类都有一个对应的虚函数表。通过虚函数表，C++ 可以以 **动态绑定** 方式调用虚函数，实现运行时的多态。

#### **2. 虚函数表的工作原理**

* **虚函数表（vtable）**：每个类（只要该类有虚函数）都会有一个虚函数表。虚函数表包含该类的虚函数的地址。虚函数表是编译器设置的静态数组，表中的每个条目是指向该类虚函数实现的指针。

* **`__vptr` 指针**：每个使用虚函数的类的对象都会有一个特殊的指针成员，称为 **`__vptr`**。`__vptr` 是一个隐藏指针，指向该类的虚函数表。它在对象创建时自动设置。

#### **3. 如何工作**

1. **虚函数表**：每个类的虚函数表存储了该类虚函数的指针。每个虚函数的条目指向最底层派生类的实现。
2. **`__vptr` 指针**：每个对象都有一个 `__vptr` 指针，它指向该类的虚函数表。
3. **动态绑定**：当调用虚函数时，程序会通过 `__vptr` 指针查找虚函数表，然后调用正确的函数。由于是动态绑定，所以即使使用基类指针，也能调用派生类的虚函数实现。

#### **4. 例子：**

```cpp
class Base {
public:
    virtual void function1() {}
    virtual void function2() {}
};

class D1 : public Base {
public:
    void function1() override {}
};

class D2 : public Base {
public:
    void function2() override {}
};
```

* **`Base` 类的虚函数表**：`Base` 类有两个虚函数，`function1()` 和 `function2()`，它的虚函数表包含这两个函数的指针，指向 `Base::function1()` 和 `Base::function2()`。
* **`D1` 类的虚函数表**：`D1` 类继承 `Base`，并重写了 `function1()`。因此，`D1` 类的虚函数表中，`function1()` 指向 `D1::function1()`，而 `function2()` 仍然指向 `Base::function2()`。
* **`D2` 类的虚函数表**：`D2` 类继承 `Base`，并重写了 `function2()`。因此，`D2` 类的虚函数表中，`function1()` 仍然指向 `Base::function1()`，而 `function2()` 指向 `D2::function2()`。

每个类实例化的时候对应的实例的vptr就会指向对应类的虚函数表，这样不论怎么向上转型，他都能够根据虚函数表找到要实际调用的自己可访问的派生函数。

#### **5. `__vptr` 指针的工作**

每个类对象都有一个 `__vptr` 指针，它指向该类的虚函数表。这个指针允许类的对象访问虚函数表，进而调用虚函数。

```cpp
class Base {
public:
    VirtualTable* __vptr; // 基类虚函数表指针
    virtual void function1() {}
    virtual void function2() {}
};
```

* `Base` 类对象的 `__vptr` 指针指向 `Base` 类的虚函数表。
* `D1` 类对象的 `__vptr` 指针指向 `D1` 类的虚函数表。
* `D2` 类对象的 `__vptr` 指针指向 `D2` 类的虚函数表。

#### **6. 示例：虚函数表的动态绑定**

```cpp
int main() {
    D1 d1 {};
    Base* dPtr = &d1;
    dPtr->function1();  // 调用 D1::function1()
    return 0;
}
```

在这个例子中：

* `d1` 是 `D1` 类型的对象，`dPtr` 是 `Base*` 类型的指针，指向 `D1` 类型的对象。
* 当调用 `dPtr->function1()` 时，**动态绑定**机制会根据 `dPtr` 实际指向的 `D1` 类型对象来调用 `D1::function1()`。

#### **7. 为什么每个类和对象都有 `__vptr` 和虚函数表**

* **每个类有虚函数表**：只要类有虚函数，就会有一个虚函数表。虚函数表存储虚函数的地址。
* **每个对象有 `__vptr`**：每个对象的 `__vptr` 指针指向该对象所属类的虚函数表。这个指针使得即使是通过基类指针，也能调用正确的虚函数实现。

#### **8. 示例：基类指针指向派生类对象**

```cpp
int main() {
    D1 d1 {};
    Base* dPtr = &d1;
    dPtr->function1();  // 调用 D1::function1()
    return 0;
}
```

* 这里，`dPtr` 是 `Base*` 类型的指针，指向 `D1` 类型的对象。即使 `dPtr` 是 `Base*` 类型，它的 `__vptr` 会指向 `D1` 类的虚函数表。通过 `dPtr` 调用 `function1()` 时，实际调用的是 `D1::function1()`。

#### **9. 性能成本**

由于虚函数需要通过虚函数表来进行动态绑定，所以虚函数调用比普通函数调用稍微慢一些。具体原因是：

* 需要通过 `__vptr` 指针查找虚函数表。
* 需要根据虚函数表中的指针调用实际的函数。
* 每个类对象有一个 `__vptr` 指针，指向该类的虚函数表，这也使得每个对象需要多占用一个指针大小。

但是，现代计算机的处理能力使得这点性能损失非常微小，通常可以忽略不计。

#### **10. 结论**

* 每个使用虚函数的类都会有一个虚函数表（`vtable`），该表存储虚函数的地址。
* 每个类对象有一个 `__vptr` 指针，指向该类的虚函数表。通过 `__vptr`，对象能够动态绑定到正确的虚函数实现。
* 虚函数表和 `__vptr` 的机制支持了 C++ 中的**运行时多态**和**动态绑定**，使得我们能够通过基类指针或引用调用派生类的函数。
